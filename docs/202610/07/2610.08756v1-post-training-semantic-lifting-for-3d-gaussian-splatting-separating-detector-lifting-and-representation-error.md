## 摘要
3D Gaussian Splatting 模型中的同一个高斯会从许多视角被观察到，而这些视角对其所属类别并不总是一致。该高斯可能在某些视角中被遮挡，并且检测器的置信度在不同视角之间也不相同。另一方面，真值以带标注的网格形式给出，因为两次训练运行不会产生相同的高斯。在这项工作中，我们提出一种训练后提升方法，它每次处理一个目标类别，并融合来自所有视角的信息。目标与非目标证据被同时累积，并以每个高斯在每个视角中的可见性作为权重。之后，用两个阈值对高斯进行过滤：主阈值 β 选择高置信度种子，较低的阈值 γβ 在其周围加入连通分量。在评估时，标签从高斯传递到既可见又有标注的网格顶点。通过这种设计，我们可以分离三种误差来源：2D 检测器、提升以及表示之间的传递。阈值和传递算子是在七个 Replica 验证场景上选定的，并在十个留出的 ScanNet++ 场景上评估，对所有场景和类别使用相同的值。验证场景上的平均 mIoU 在使用数据集标注掩码时为 0.93，在使用 YOLO 掩码时为 0.65；在 ScanNet++ 测试场景上则分别为 0.80 和 0.54。与先前版本按视角对证据进行阈值化相比，该比例将测试 mIoU 提高了 0.24，并使得可以对两个数据集的所有类别和场景使用单一阈值。最后，误差分析表明，剩余误差的大部分来自检测器。

## Abstract
The same Gaussian of a 3D Gaussian Splatting model is seen from many views, and these views do not always agree on the class it belongs to. The Gaussian may be occluded in some of them, and the confidence of the detector is not the same from one view to another. The ground truth, on the other hand, is given as an annotated mesh, because two training runs do not produce the same Gaussians. In this work, we propose a post-training lifting method that works with one target class at a time and combines the information coming from all the views. Target and non-target evidence are accumulated simultaneously, weighted by the visibility of each Gaussian in each view. After that, the Gaussians are filtered with two thresholds: a main threshold $β$ selects the high-confidence seeds, and a lower one $γβ$ adds the connected components around them. For the evaluation, the labels are transferred from the Gaussians to the mesh vertices that are both visible and annotated. With this design, we can separate three sources of error: the 2D detector, the lifting and the transfer between representations. The thresholds and the transfer operator are chosen on seven Replica validation scenes, and the method is evaluated on ten held-out ScanNet++ scenes with the same values for every scene and class. The mean mIoU on the validation scenes was 0.93 with masks from the dataset annotations and 0.65 with YOLO masks, and on the ScanNet++ test scenes it was 0.80 and 0.54. Compared with thresholding the evidence per view, as a previous version of the method did, the fraction improves the test mIoU by 0.24 and makes it possible to use a single threshold for all the classes and scenes of both datasets. Finally, the error analysis shows that most of the remaining error comes from the detector.

# 论文总结：3D Gaussian Splatting 的训练后语义提升

## 1. 核心问题与整体含义

- **背景**：3D Gaussian Splatting（3DGS）用各向异性 3D 高斯表示场景，每个高斯只存几何与外观参数（位置、协方差、不透明度、球谐系数），**不含类别信息**。语义通常来自 2D 检测器在重建图像上产生的掩码，再投影回高斯。
- **核心矛盾一（多视角不一致）**：同一个高斯会被多台相机看到，但这些视角对它的类别判断并不一致——它可能在部分视角被遮挡，检测器在不同视角的置信度也不同。
- **核心矛盾二（表示不匹配）**：真值以**带标注的网格**给出（因为两次训练不会产生相同的高斯），而高斯中心是稀疏点云。一个在高斯上看起来正确的标注，转移到网格后仍会因高斯的各向异性形状与深度差异而损失精度。
- **整体含义**：作者提出一种**训练后（post-training）语义提升**方法，逐类融合全部视角信息，并设计了一套评估协议，能够**把最终误差分解为「2D 检测器」「提升过程」「表示间传递」三个来源**，从而回答“精度到底丢在流水线的哪一环”。

## 2. 方法论

### 2.1 核心思想

- 把分割建模为**逐目标类别的 one-vs-rest 问题**，每个类别独立运行一次。
- 在同一次遍历中，对每个高斯**同时累积目标证据 E⁺ᵢ 与非目标证据 E⁻ᵢ**，两者使用**同一套可见性权重**（即面对同样的遮挡与可见性，唯一区别是掩码），最终用**目标证据分数** ρᵢᵏ = E⁺ᵢ / (E⁺ᵢ + E⁻ᵢ) ∈ [0,1] 做判定。
- 用**双阈值 + 空间滞后（hysteresis）**替代单一硬阈值：主阈值 β 选出高置信“种子”，较低的 γβ 在连通图上把与种子相连的分量一并纳入。

### 2.2 六个阶段的关键细节

1. **2D 掩码与置信度**：每幅图给出标签图 Lᵥ 与置信图 qᵥ。像素被分为目标集 P⁺ᵥ 与非目标集 P⁻ᵥ；有检测的像素置信度为“软掩码值 × 检测分数”，**无检测的背景像素赋固定置信度 q₀ = 0.25**。数据集标注掩码写成同一格式（置信度恒为 1），因此两种来源走完全相同的后续流程。
2. **均值与协方差投影**：世界坐标经刚体变换到相机系，只保留 zᵢ > 0 的高斯；用针孔模型得到投影中心；协方差按 EWA splatting 的局部仿射近似投影 Σ′ᵢ = Jᵢ W Σᵢ Wᵀ Jᵢᵀ，并**加 0.3 px² 低通滤波**以保证亚像素高斯可逆，再存为三个 conic 系数 (A, B, C) 以避免逐像素求逆；由最大特征值取保守半径 rᵢ = ⌈3√λᵢ⌉。
3. **Tile 光栅化与可见性权重**：图像切成 16×16 像素瓦片，逐瓦片张量广播计算 alpha 值 αᵢ,ₚ = oᵢ·exp(高斯核)，按深度前后排序做 alpha 合成，得到透射率 Tᵢ,ₚ 与贡献 **wᵢ,ₚ = αᵢ,ₚ·Tᵢ,ₚ**——这就是该视角对第 i 个高斯的语义证据权重，被遮挡的高斯权重趋近 0。
   - 与官方 CUDA 实现的两点差异：**裁剪更严格**（高斯中心必须落在视锥内，防止视锥外的大高斯“越界收集”证据）；**不做提前截断**（不因 alpha 过小或透射率耗尽而提前终止）。
4. **证据累积**：E±ᵢ = Σ_{v∈Vₖ} Σ_{p∈P±ᵥ} qᵥ(p)·wᵢ,ₚ，其中 Vₖ 是**确实含该类别的相机集合**。不含该类的相机被整体跳过，否则稀有类别的分数会被无类相机稀释，阈值含义会随类别漂移。支持集 Sₖ 定义为 E⁺ᵢ + E⁻ᵢ > 0。
5. **阈值与空间滞后**：种子集 Sₖ_β = {i : ρᵢᵏ ≥ β}；在“中心距离 ≤ η（0.05 m）”的图连通定义下，**只要一个连通分量包含至少一个种子，该分量的所有高斯都被标为目标类**（γβ ≤ ρᵢᵏ < β 的为候选）。证据本身不做传播，因此 ρᵢᵏ 不变。
6. **从高斯到网格的传递**：考察两种算子（邻居半径 τ = 0.10 m）：
   - **最近高斯（Nearest Gaussian）**：顶点直接取最近高斯的标签；
   - **半径投票（Radius vote）**：邻域内每个高斯以权重 νᵢ(v) = max(oᵢ, o_min) / (‖μᵢ − v‖² + ε) 投票（距离越近、越不透明权重越大），当 S⁺/(S⁺+S⁻) ≥ θ（θ = 0.3 < 0.5）时顶点获胜，因此标注区域可比被选高斯**向外扩张最多 τ**。
   - **真值转移参考**：把网格标注先经半径投票（均匀权重）送到高斯，再用与预测相同的算子送回网格。预测与参考的唯一差别是“高斯标签从哪来”，因此该参考量化了**表示 + 传递**的损失上限。

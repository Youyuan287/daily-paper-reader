## 摘要
具有语义理解的稠密三维建图对于复杂环境中的机器人感知至关重要。近期基于三维高斯泼溅的建图方法能够实现高保真几何与高效的开放词汇感知，但通常将语义表示为非结构化特征场，这限制了以对象为中心的推理。相比之下，三维场景图显式建模对象及其关系以进行结构化推理，但通常由稀疏几何表示构建，未能充分利用稠密语义地图。在这项工作中，我们提出 OpenSplatGraph，一个统一框架，可直接从基于高斯的在线开放词汇语义地图构建持久化三维场景图。所提出的框架利用可靠性感知语义场增强稠密语义地图，该语义场维护轻量级观测统计，用于置信度感知、查询条件化的对象提取。提取的对象实例与持久图节点关联，使对象属性和关系能够在观测与查询之间增量更新。通过将稠密语义建图与持久化的以对象为中心表示紧密耦合，我们的框架支持语言引导的对象定位和结构化关系推理，同时保持基于高斯的建图的几何保真度。在标准三维场景理解基准和真实机器人实验上的全面评估表明，OpenSplatGraph 在在线开放词汇感知和下游机器人任务上取得了有竞争力的性能。项目页面：https://csiro-robotics.github.io/OpenSplatGraph。

## Abstract
Dense 3D mapping with semantic understanding is essential for robotic perception in complex environments. Recent 3D Gaussian Splatting-based mapping approaches enable high-fidelity geometry and efficient open-vocabulary perception, but typically represent semantics as unstructured feature fields that limit object-centric reasoning. In contrast, 3D scene graphs explicitly model objects and their relationships for structured reasoning, but are commonly constructed from sparse geometric representations that do not fully exploit dense semantic maps. In this work, we present OpenSplatGraph, a unified framework that constructs persistent 3D scene graphs directly from an online Gaussian-based open-vocabulary semantic map. The proposed framework augments the dense semantic map with a reliability-aware semantic field that maintains lightweight observation statistics for confidence-aware, query-conditioned object extraction. Extracted object instances are associated with persistent graph nodes, allowing object attributes and relationships to be incrementally updated across observations and queries. By tightly coupling dense semantic mapping with persistent object-centric representations, our framework supports both language-guided object grounding and structured relational reasoning while preserving the geometric fidelity of Gaussian-based mapping. Comprehensive evaluations on standard 3D scene understanding benchmarks and real-world robotic experiments demonstrate that OpenSplatGraph achieves competitive performance for online open-vocabulary perception and downstream robotic tasks. Project page: https://csiro-robotics.github.io/OpenSplatGraph.

## 2. 方法论
- **核心思想**：不把稠密语义场和场景图视为二选一的替代表示，而是全程共同维护。稠密语义场负责几何/语义基础与查询条件对象提取；持久场景图增量积累对象身份、属性和关系，用于结构化推理。
- **混合语义建图**：采用 TSDF 体素几何 + 3D Gaussian 原语的混合地图。RGB-D 观测经 SAM/MobileSAMv2 提取实例掩码，并用 CLIP/OpenCLIP 编码为语言对齐语义特征。
- **体素语义融合**：每个体素维护融合语义嵌入、观测次数、累计语义置信和全局坐标。新观测按置信度加权与历史嵌入融合，低置信观测影响被抑制；融合后更新观测计数和累计置信。
- **可靠性感知语义场**：除观测次数与累计置信外，增加逐体素残差语义不一致性，用归一化余弦不一致的指数移动平均更新。实例置信分数综合“观测强度”和“语义稳定性”，无需监督校准，用于候选对象排序与过滤。
- **查询条件对象提取**：给定语言查询，计算文本嵌入与体素语义嵌入的余弦相似度；阈值筛选高相似体素，再用 DBSCAN 在欧氏空间聚类；对每个簇计算质心、AABB、平均相似度、可靠性置信；按相似度与置信加权排序，保留 top-K 实例。
- **持久场景图构建**：将新提取实例与历史实例关联。关联时仅在同一语义标签内寻找最近且未匹配的质心，若距离小于阈值则复用持久 ID，否则分配新 ID。图节点存储 ID、标签、质心、AABB、置信和几何属性；图边包含在线空间关系和可选开放语义关系。
- **关系建模**：
  - 在线空间关系：基于质心与 AABB 的几何测试，如 near、on/under、inside、相对顺序等，并赋予几何置信。
  - 开放语义关系：异步使用 VLM，对渲染关键帧叠加实例 ID，预测有向关系三元组，并通过多视角投票聚合，保留足够支持度的关系。

## 3. 实验设计
- **数据集与场景**：
  - ScanNet 与 Replica：评估开放词汇 3D 语义分割。
  - Replica：按 ConceptGraphs 协议评估 3D 对象 grounding。
  - 真实室内环境：Stretch 3 移动操作机器人 + Intel RealSense D435i + ORB-SLAM3，验证语言引导导航与操作。
- **Benchmark 与任务**：
  - 开放词汇 3D 语义分割：mIoU、mAcc、FPS。
  - 3D 对象 grounding：描述性、可供性、否定三类查询；CLIP 检索与 LLM 检索；Recall@1/2/3。
  - 直接场景图评估：节点精度、边精度、重复节点率。
- **对比方法**：
  - 语义分割：LangSplat、OpenGaussian、InstanceGaussian、ConceptFusion、OpenGS-Fusion；补充对比 GaussianGraph、DynamicGSG。
  - 对象 grounding 与图评估：ConceptGraphs。
- **主要定量结果**：
  - ScanNet：OpenSplatGraph mIoU 36.75、mAcc 53.82；在线设置下优于 ConceptFusion 和 OpenGS-Fusion，接近离线 InstanceGaussian。
  - Replica：mIoU 35.37、mAcc 47.67；在线性能有竞争力。
  - Grounding：在可供性和否定查询上提升明显；例如否定查询 CLIP R@1 达 0.51，优于 ConceptGraphs 的 0.26；LLM 检索在否定查询上达到 0.80/0.89/0.94。
  - 消融：可靠性语义建模显著提升分割；持久对象关联使 R@1 达 0.36；加入场景图推理后 R@1 提升至 0.50。
  - 补充图评估：节点精度 0.73、边精度 0.91、重复节点率 5.94%，优于 ConceptGraphs 的 0.71、0.88、6.77%。

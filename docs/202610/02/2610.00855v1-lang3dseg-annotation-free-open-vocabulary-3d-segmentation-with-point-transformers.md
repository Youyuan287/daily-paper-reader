## 摘要
准确的3D语义感知对于安全的自动驾驶导航至关重要。然而，有监督的LiDAR分割仍受限于封闭分类体系以及逐点人工标注的成本。开放词汇方法通过将2D视觉语言模型的输出投影到LiDAR上，并将其蒸馏到3D网络中，从而避免了这一成本。这些方法几乎完全依赖基于体素的稀疏卷积，而点Transformer迄今仅限于室内环境，那里的3D数据稠密且有界。我们提出Lang3DSeg，它将点Transformer确立为户外3D LiDAR无标注开放词汇分割的主干网络，并且无需几何预训练即可从零开始训练。这种训练范式必须解决2D到3D标签投影中固有的噪声；具体而言，朴素投影常常受到深度歧义的影响，即物体后方的点被错误地赋予该物体的语义标签。因此，我们使用显式的类别优先级规则来合成掩码，并在每个投影实例的深度分布中的第一个间隙处将其截断，直接校正投影误差，而不是在配准序列上对其进行平均。Lang3DSeg在nuScenes验证集上达到52.8% mIoU，在SemanticKITTI上达到41.4%，在两个基准上均为已发表的无标注方法中最高。每次3D语义分割均基于单帧LiDAR扫描，且推理可实时运行，无需运行视觉语言模型。

## Abstract
Accurate 3D semantic perception is critical for safe autonomous navigation. However, supervised LiDAR segmentation remains tied to closed taxonomies and to the cost of point-wise manual annotation. Open-vocabulary methods avoid that cost by projecting the output of 2D vision-language models onto LiDAR and distilling it into a 3D network. These methods rely almost exclusively on voxel-based sparse convolutions, and point transformers have so far been limited to indoor environments, where 3D data is dense and bounded. We present Lang3DSeg, which establishes a point transformer as the backbone for annotation-free open-vocabulary segmentation of outdoor 3D LiDAR, and is trained from scratch without geometric pre-training. This training paradigm necessitates addressing the inherent noise in 2D-to-3D label projections; specifically, naive projection often suffers from depth ambiguity, where points behind an object are erroneously assigned its semantic label. We therefore composite masks using an explicit class-priority rule and truncate each projected instance at the first gap in its depth distribution, correcting the projection error directly rather than averaging it over registered sequences. Lang3DSeg achieves 52.8% mIoU on nuScenes validation and 41.4% on SemanticKITTI, the highest among published annotation-free methods on both benchmarks. Every 3D semantic segmentation is on a single LiDAR sweep, and inference operates in real-time without running vision-language models.

## 一、核心问题与整体含义

- **研究动机**：准确的 3D 语义感知是自动驾驶安全导航的基础。有监督 LiDAR 分割存在两大瓶颈：依赖闭集分类体系（无法识别训练时未定义的类别），以及逐点人工标注的高昂成本。
- **开放词汇路线的现状**：现有开放词汇方法通过 2D 视觉语言模型（VLM）为图像打标，再投影到 LiDAR 上蒸馏给 3D 网络，从而规避人工标注。但这些方法几乎全部依赖**基于体素的稀疏卷积**（SPVCNN、MinkowskiNet、WaffleIron 等），引入了原始点测量中不存在的空间量化。
- **点 Transformer 的空白**：点 Transformer 已在室内开放词汇分割中使用（如 SpaCeFormer），但室内场景稠密、有界、采样均匀；室外 LiDAR 恰好相反——稀疏、环状结构、跨度达百米，点密度随距离平方衰减。据作者所知，**尚无点 Transformer 被用于室外无标注开放词汇分割**。
- **关键难点**：从零训练的点 Transformer 没有先验可以抑制投影伪标签中的噪声，其中最典型的是**深度歧义**——物体后方的点被错误赋予该物体的语义标签（"遮挡渗漏"）。作者指出这类误差是**系统性**而非统计性的：车后的点从任何相似视角看都会被同样错标，因此时序投票只会强化错误，而判断所需的信息（沿相机射线的深度）在投影时本就可得却被丢弃。

## 二、方法论

### 核心思想
用点 Transformer（PointTransformerV3）作为骨干，从零训练、无几何预训练，实现室外 3D LiDAR 的**无标注开放词汇**分割；并把投影误差在**投影阶段本身**直接消除，而非事后统计补偿。整个框架分三阶段：离线目标策展 → 从零训练 PTv3 → 组合损失。

### 关键技术细节

**（1）离线目标策展（仅用单帧扫描，无配准、无跨帧投票）**

- **描述性提示**：用自然语言短语集合（而非数据集类别字符串，如"other flat"这种基础模型无法识别的标签）查询 SAM 3。短语集设计受基准定义约束，例如 nuScenes 把停车场归为 drivable surface、广场归为 sidewalk，若按"other flat"提示反而会从两个表现良好的类别中移除点。SAM 3 以视频模式在连续 5 个关键帧窗口上运行以摊销文本接地成本，但仅做 2D 掩码跟踪，不配准或合并点云。
- **优先级排序光栅化**：所有类别的掩码需合成为单张 2D 标签图，合成顺序至关重要。由于 drivable-surface 掩码覆盖大部分画面且置信度高，若按置信度排序会抹掉其上的交通锥和行人。因此给每类固定优先级 π(c)，**细小前景类别最高、路面最低**，像素归属规则为：

  > 写入 ⇔ (π(c) > π⋆) ∨ (π(c) = π⋆ ∧ s > s⋆)

  即优先级决定类间胜负，置信度仅在同一类内打破平局。

- **投影与遮挡剔除**：点变换到各相机坐标系时保留沿光轴的深度 dᵢ。逐像素深度缓冲无效，因为被遮挡点投影到的是掩码内另一个像素。作者利用"物理物体在深度上连续、其后方表面被空隙隔开"这一事实：对每个实例 m 将其点的深度排序 d₍₁₎ ≤ … ≤ d₍ₙ₎，保留到**第一个足够大的间隙**为止的前缀：

  > k⋆ = min{ k : d₍ₖ₊₁₎ − d₍ₖ₎ > τ_d }，保留 { (1), …, (k⋆) }

  取 τ_d = 2.5 m，可移除车后数米的墙，同时保留自身深度连续的公交车/挂车。该测试**仅对前景类**施加（背景区域本就合法地深度延伸）。多相机可见的点按上述优先级规则合并，重叠视角充当弱集成。

- **地平面净化**：2D 分割器常把平坦地形与垂直植被混淆（草地边缘与树冠外观难分），故用几何方法解决。在 40 m 内对 drivable surface 点用 RANSAC 拟合平面 (n, d)，拒绝 n_z < 0.90 的假设并用最小二乘精化。每点有符号高程 eᵢ = nᵀpᵢ + d，当满足

  > |eᵢ| < τ_e ∧ (邻域内 z 极差) < τ_z

  时把 vegetation 重标为 terrain，取 τ_e = 0.35 m、τ_z = 0.5 m、邻域半径 r = 1.0 m。第二个条件保护树干（基部贴近地面但邻域跨数米高）。15 m 内还额外要求局部平面性：由协方差特征值定义平面度 Pᵢ = (λ₂−λ₃)/λ₁、表面变化率 vᵢ = λ₃/Σλₖ 和法向 v₃，要求 Pᵢ > 0.35、vᵢ < 0.20、|v₃,z| > 0.80。近场限制源于采样几何：32 线传感器在 10 m 处相邻环间距约 1.3 m，20 m 处约 5 m，更远处协方差退化，故式(3)的**与距离无关的高程检验仍是主要信号**。
- **标签补全**：相机覆盖不全导致部分点无标签。对未标注点，在 0.4 m 内取 k 个最近已标注邻居，仅当至少找到 3 个且全部一致时填充。该步骤**严格增量**，从不覆盖已有标签，提升覆盖率而不引入无约束平滑的抖动。

**（2）网络**

- 骨干为 PointTransformerV3，**从零初始化**，无几何预训练、无监督初始化。
- 编码器通道宽度 (32, 64, 128, 256, 512)，深度 (2, 2, 2, 6, 2)，阶段间步长 2；解码器宽度 (64, 64, 128, 256)；点在 0.05 m 网格上用 z-order 和 Hilbert 曲线序列化。
- 网络消费单帧扫描，输出密集 logits Z ∈ ℝ^(N×K) 和嵌入 H ∈ ℝ^(N×512)。
- 输入表示：坐标**仅在 x、y 上中心化**，垂直轴保留在传感器坐标系中（因为高度正是本文目标类别间的区分依据，且对 z 均值中心化会在训练样本与推理用完整扫描不同时引入训练–测试偏移）。每点特征为 [x′, y′, z, ι]，ι 为归一化回波强度。

**（3）目标函数**

- **语义项**：加权交叉熵 + Lovász-Softmax（直接优化 IoU 代理）：

  > L_CE = −(1/|V|) Σ_{i∈V} w_{yᵢ} log( exp(z_{i,yᵢ}) / Σ_j exp(z_{i,j}) )

  仅在携带策展标签的点集 V 上计算。类别权重采用**逆平方根频率** w_c ∝ f_c^(−1/2)，归一化到单位均值并裁剪到 [0.2, 8]，f_c 在策展目标上测量。作者指出不带平方根的逆频率会过度加权稀有类，与 Lovász-Softmax 组合时训练不稳定，后者因 logits 接近均匀时条件数差而线性预热 3 个 epoch。
- **余弦对齐项**：

  > L_dist = (1/|V|) Σ_{i∈V} ( 1 − ⟨ hᵢ/‖hᵢ‖₂ , t_{yᵢ} ⟩ )

  t_{yᵢ} 是所指类别来自**冻结的 clip-vit-base-patch32** 文本编码器（投影到联合图文空间后）的单位范数锚点。锚点仅通过该项进入训练，**不在前向路径中**，故推理不需要文本编码器。除正则化外，该术语使嵌入可被文本查询：训练分类体系之外的类别可通过 H 与任意文本嵌入的余弦相似度打分而无需重训练。
- **总目标**：L = λ_ce·L_CE + λ_lov·L_lov + λ_dist·L_dist，取 λ_ce = λ_lov = 1.0、λ_dist = 0.1（经验确定）。

## 摘要
近期三维重建的进展已从逐场景优化发展到前馈推理，语义场景理解也紧随其后——然而现有方法仍局限于以对象为中心的感知，忽视了对象之间的空间关系。我们将三维空间关系分割形式化为一种前馈、无需位姿的多视图设定：给定视觉指定的主体和关系文本查询，模型跨视图分割目标，且不接收其类别名称。为此，我们提出 RelationVGGT，一种新颖的前馈框架，它将来自视觉基础模型的语义特征与来自三维几何基础模型的几何感知表示相结合，并利用关系 Transformer 进行以主体为条件、跨视图的关系预测——既不需要逐场景优化，也不需要已知相机位姿。此外，我们提供了一个基于 ScanNet++、使用 VLM 和 LLM 构建的全自动标注流程，从而能够为这一新任务实现可扩展的训练数据生成。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

## 1. 核心问题与研究动机

- **背景趋势**：三维重建领域已从 NeRF、3DGS 等逐场景优化范式，转向 DUSt3R、VGGT 等前馈式视觉几何模型；语义场景理解也随之从逐场景方法（LangSplat、OpenGS）走向前馈方法（PanSt3R、Uni3R），逐步摆脱对已知相机位姿与逐场景优化的依赖。
- **现有不足**：上述方法仍以"对象中心"感知为主，把场景视为孤立实体的集合，忽视对象之间的空间关系。然而，理解"显示器放在桌上""杯子在键盘旁"这类关系，是空间问答与具身智能体行动的核心能力。
- **任务定义（3D Spatial Relation Segmentation）**：在多视图、无位姿、前馈设定下，给定参考视图的主体掩码 $M^s$ 与关系文本查询 $q$（如 "resting on"），模型需在所有目标视图中分割出满足该空间关系的**目标对象**——**且不接收目标类别名**。
- **两大现有路线的局限**：
  - **RelationField**：在辐射场上学习关系特征 $g_\theta(x,z)\to r$，但需逐场景优化与标定相机位姿，且要在整个 3D 体素上搜索目标，计算昂贵、泛化差。
  - **视频-语言模型**：缺乏 3D 场景表示，在大视角变化下难以保持对象对应关系。
- **核心洞察**：给定参考视图主体掩码后，**无需在稠密 3D 体积中搜索**，可将"体素关系搜索"重构为**目标视图图像网格上的逐像素关系预测**，从而避免场景特定 3D 场依赖。

## 2. 方法论

### 2.1 核心思想
将关系定位形式化为条件于参考主体的逐像素关系特征预测：学习函数 $f_\theta(I_r, M^s, I_{tgt}, u) \to R^t$，为每个目标视图位置 $u$ 输出一个可与语言嵌入对齐的关系特征 $r_t(u)\in\mathbb{R}^D$，再通过特征-文本相似度得到分割掩码。

### 2.2 关键技术细节

- **特征提取（双流融合）**
  - 语义流：DINOv2 提供稠密 patch 级对象语义 $E_n^D$。
  - 几何流：Pi3 编码器（在预测头之前）提供多视图几何感知表示 $E_n^P$。
  - 通过输入混合器（线性投影 + 少量带 RoPE 的 Transformer 块）沿通道拼接并映射为联合 token $F_n\in\mathbb{R}^{P\times d_f}$。

- **主体表示（保留空间布局）**
  - 不将主体压缩为单一池化向量，而是保留参考视图全部 patch token，仅将非主体 patch 置零：$F_r^s = \bar{M}^s \odot F_r$，从而保留主体的空间布局与细粒度语义。

- **关系 Transformer（交替注意力）**
  - 将所有目标视图 token 拼接为序列 $Z^0$，逐层交替执行：
    - **主体条件交叉注意力**：$\bar{Z}^\ell = \text{CrossAttn}^\ell(Z^\ell, F_r^s)$，使每个目标 patch 关注主体 token；
    - **多视图自注意力**：$Z^{\ell+1} = \text{SelfAttn}^\ell(\bar{Z}^\ell)$，实现跨视图信息交换。
  - 输出经 DPT 掩码头上采样为像素对齐的关系特征图 $R^t = \text{Dec}(Z_t^L)$。

- **3D 几何辅助**：用 Pi3 点解码器预测点图与置信度图，将每个关系特征 $r_t(u)$ 关联到对应 3D 点，形成置信度感知的 3D 关系表示。

- **训练目标（多查询监督）**
  - 观察到同一空间关系可有多种有效表述（"standing on"/"on"/"supported by"），故将同一目标掩码用多个兼容关系查询**独立监督**（非互斥分类），避免惩罚语义合理的替代表述。
  - 损失：$\mathcal{L}_{mask} = w_{focal}\mathcal{L}_{multi\text{-}q\,focal} + w_{dice}\mathcal{L}_{dice}$，其中 focal loss 对像素与查询双重平均（$\alpha=0.75,\ \gamma=1.5$）。

- **推理**：关系 logit $z_t(u;q) = r_t(u)^\top e(q)$，经 sigmoid 得分数，以固定阈值 $\tau=0.3$ 二值化；实验发现无需负提示归一化。

### 2.3 自动化标注流水线（基于 ScanNet++）
1. **初始场景图**：以 3D 实例为节点，边初始为空。
2. **VLM 关系提取**：将实例掩码投影到 RGB 帧，用 SoM 提示标记可见对象，查询 Qwen3-VL-8B 得到逐帧关系提议（开放词汇、有向）。
3. **多视图一致性过滤**：要求同一对象对至少 $K=3$ 帧一致预测，否则拒绝；通过后将关系传播到所有共视帧。
4. **几何过滤**：利用 3D 包围盒与质心，剔除包围盒不重叠且质心距离超阈值的物理不合理关系。
5. **LLM 改写**：用 GPT-5.2 将验证三元组（subject, relation, target）改写为多样表达（如 (TV, hanging on, wall) → "mounted on"），扩充词汇多样性。

## 6. 主要结论与发现

- **定量结果**：本方法平均 **mIoU 0.382、mAcc 0.549**，全面超越最强基线 RelationField（0.303 / 0.480）；在 Replica（0.446/0.640）与 ScanNet++（0.445/0.675）上提升显著，LERF（0.254/0.332）因桌面杂乱场景而偏低，但仍与使用 GT 类别名的 RelationField 相当。
- **优于视频基础模型**：UniPixel 在小基线场景有竞争力，但随基线增大性能下降；本方法在**所有基线范围保持稳定**，归因于 3D 基础模型主干提供的视图不变性。
- **无需目标类别查询**：本方法仅靠关系推理定位目标，是其与先前方法的关键区别。
- **对主体掩码不精确鲁棒**：SAM2 单击/框提示几乎不损失性能；失败主因是主体实例歧义（58% 参考视图含多个同类实例）而非边界精度。
- **对谓词改写鲁棒**：同义改写仅轻微下降，罕见/未见表达下降有限，说明关系预测不依赖训练中见过的确切字符串。
- **标注流水线有效性**：几何+多视图过滤将提议精确率从 36.4% 提升到 67.2%，剔除 92.0% 的错误提议（但仅保留 28.5% 的正确提议，属有意牺牲召回换精度）。

## 7. 优点

- **任务形式化新颖**：首次将 3D 空间关系分割定义为前馈、无位姿、多视图设定，且不提供目标类别名，要求语义身份 + 方向性关系 + 跨视图几何一致性三者结合。
- **方法设计巧妙**：把昂贵的 3D 体素关系搜索重构为图像网格上的逐像素预测，既避免场景特定优化，又通过 3D 基础模型主干隐式获得视图不变性。
- **主体表示保留空间布局**：不池化为单向量，保留细粒度语义，支撑跨视图条件推理。
- **多查询监督**：契合空间关系"多对一"本质，避免惩罚语义合理的替代表述。
- **自动化数据流水线**：结合 VLM 提取、多视图一致性、几何过滤与 LLM 改写，可扩展生成多视图一致的关系标注。
- **效率优势显著**：26 ms 前馈推理 vs. 288 s + 3 h 优化的对比极具说服力。
- **鲁棒性与可解释性分析扎实**：掩码来源、谓词改写、意义改变控制、主体可见性等实验设计有针对性。

## 8. 不足与局限

- **数据依赖**：标注流水线依赖具备实例级标注的数据集（如 ScanNet++），难以直接扩展到无标注或野外场景。
- **标注噪声**：过滤后精确率仅 67.2%，保留的训练监督仍含噪声；多视图一致性 $K=3$ 要求导致大量正确关系被丢弃（正确保留率 28.5%），训练覆盖率受限。
- **关系范围有限**：仅建模对象-对象空间关系，未涉及功能关系，也未与全景分割分支联合预测场景图节点与边。
- **部分基准性能偏低**：LERF 上 mIoU 仅 0.254，杂乱桌面场景仍是难点。
- **对比公平性**：与 MVGGT、ReferSplat、视频模型的对比存在输入接口、预训练数据、优化协议的不一致，作者亦承认并非严格匹配的消融。

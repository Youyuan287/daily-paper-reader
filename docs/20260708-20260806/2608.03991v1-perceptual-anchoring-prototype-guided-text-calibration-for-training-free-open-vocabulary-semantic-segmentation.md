## 摘要
免训练开放词汇语义分割（OVSS）根据任意文本描述将图像分割成语义不同的区域，无需学习任何额外参数。然而，现有方法通常侧重于改进视觉表示，而将仅编码通用类别概念的文本嵌入视为固定的分类参考。这些通用概念与捕获目标实例特定外观的视觉表示之间产生的语义差距，往往导致不完整的掩码和非目标区域的错误预测。受感知锚定中符号-知觉对应关系的启发，我们提出了用于免训练OVSS的原型引导文本校准（PTC）。在感知阶段，PTC根据初始匹配分数选择可靠的视觉证据来构建类别特定的视觉原型。在锚定阶段，PTC利用这些原型校准其对应的文本嵌入，校准强度根据视觉证据的数量自适应调整。因此，校准后的文本嵌入在保留通用类别语义和开放词汇泛化能力的同时，更准确地与实例特定的视觉表示对齐。此外，PTC既不需要额外训练，也不需要外部模型，可以作为现有方法的即插即用模块。跨八个基准的大量实验表明，PTC显著提升了六种代表性方法的性能，并产生更完整、更准确的分割结果。这些结果验证了PTC作为一种简单有效的改进视觉-文本对齐的方法。

## Abstract
Training-free open-vocabulary semantic segmentation (OVSS) partitions an image into semantically distinct regions based on arbitrary text descriptions, without learning any additional parameters. However, existing methods typically focus on improving visual representations while treating text embeddings that encode only generic category concepts as fixed classification references. The resulting semantic gap between these generic concepts and the visual representations that capture the specific appearances of target instances often causes incomplete masks and erroneous predictions in non-target regions. Inspired by the symbol-percept correspondence underlying perceptual anchoring, we propose Prototype-Guided Text Calibration (PTC) for training-free OVSS. In the Perceiving stage, PTC selects reliable visual evidence based on initial matching scores to construct category-specific visual prototypes. In the Anchoring stage, PTC uses these prototypes to calibrate their corresponding text embeddings, with the calibration strength adaptively adjusted based on the amount of visual evidence. Consequently, the calibrated text embeddings align more accurately with instance-specific visual representations while preserving generic category semantics and open-vocabulary generalization. Moreover, PTC requires neither additional training nor external models and can serve as a plug-and-play module for existing methods. Extensive experiments across eight benchmarks show that PTC significantly enhances the performance of six representative methods and yields more complete and accurate segmentation results. These results validate PTC as a simple and effective approach to improving visual-text alignment.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：开放词汇语义分割（Open-Vocabulary Semantic Segmentation, OVSS）旨在根据任意文本描述将图像分割为语义区域。免训练（training-free）的 OVSS 无需学习额外参数，因而便于泛化到新场景和类别，近年受到广泛关注。
- **现有方法的问题**：已有免训练方法大多致力于改进视觉特征（如增强局部感知与空间一致性），但将类别文本嵌入视为固定的零样本分类器。文本嵌入由预训练语言模型编码，表达的是通用、输入无关的类别概念；而视觉特征从具体图像提取，刻画的是目标实例在特定姿态、视角和成像条件下的外观。二者之间存在**语义鸿沟**，直接匹配会导致两类缺陷：
  1. 只识别高度类代表性的局部区域，造成分割掩码不完整；
  2. 通用文本嵌入易与视觉相似背景或共现类别错误匹配，产生误分割。
- **核心洞察**：借鉴认知机器人中的“感知锚定”（perceptual anchoring）概念——将抽象符号与具体知觉对象建立联系，让符号能指向特定实体——作者认为类别文本嵌入不应固定不变，而应利用图像中的可靠视觉证据将抽象类别概念“锚定”到具体目标实例上，从而缩小语义间隙、提升分割精度。
- **整体意义**：提出一种**原型引导的文本校准（PTC）**方法，作为免训练 OVSS 的即插即用模块，无需额外训练或外部模型，能同时保留通用类别语义并纳入实例化外观信息，显著改善视觉-文本对齐与分割质量。

## 2. 论文提出的方法论（核心思想、关键技术细节）

### 2.1 总体框架
- 输入图像 → 冻结的 CLIP 视觉编码器得到视觉特征 F；类别名 → 冻结的文本编码器得到通用类别文本嵌入 T。
- 计算初始匹配分数 S = cos(F, T)，得到初始分割预测。
- PTC 分为两个阶段：
  - **Perceiving（感知）**：依据初始分数筛选可靠视觉证据，构造类别特定的视觉原型。
  - **Anchoring（锚定）**：用视觉原型校准文本嵌入，得到校准后的 Tcal，再计算新分数 S_new = cos(F, Tcal) 并生成最终分割图。

### 2.2 Perceiving：可靠视觉原型构建
- **候选集定义**：对每个类别 c，令 Ωc = {i | 初始预测类别为 c}，Nc = |Ωc|。
- **基于边际的可靠性评估**：
  - 计算每个 token 的分数边际 Δi = 最高分数 − 第二高分数。
  - 边际越大说明类别分配歧义越小，较之“绝对置信度”能更好过滤对多个类别都高响应的歧义 token。
- **混合证据量确定策略**：
  - 目标证据数 Kc = min(Nc, max(Kmin, ⌊ρNc⌋))，其中 Kmin 为最小证据数，ρ 为采样比例（默认 0.1）。
  - 小候选集由 Kmin 保证代表性，大候选集按比例增加证据覆盖，Nc 作为上界；Nc < Kmin 的类别视为证据不足，不参与后续原型构建与校准。
- **证据选择与原型聚合**：
  - 选取边际最大的 Kc 个 token 作为证据集 Ec。
  - 用边际作为权重加权求和得到视觉原型 Vproto_c = Σ_{i∈Ec} w_i f_i，权重大者歧义更小，提高原型稳定性。

### 2.3 Anchoring：证据驱动的文本校准
- **合格类别判定**：证据数 n_c ≥ Kmin 的类别才进行校准，否则保留原文本嵌入，防止有限证据造成语义偏移。
- **自适应校准强度**：
  - 对合格类别，μc = μ · αc，其中 αc = min(1, log(1+n_c)/log(1+λKmin))。
  - μ 为全局校准强度上界，λ 控制达到上界所需证据量（默认 λ=10）。
  - 证据较少时校准保守，证据充分后强度饱和，避免大目标因证据多而过度偏离原语义。
- **文本更新**：
  - tcal_c = (1−μc)·tc + μc·Vproto_c（合格类别）；
  - tcal_c = tc（不合格类别）。
- **最终预测**：S_new = cos(F, Tcal)，Mnew = argmax_c S_new。

## 6. 论文的主要结论与发现

- PTC 能有效缓解免训练 OVSS 中通用文本嵌入与实例视觉特征之间的语义鸿沟。
- 将 PTC 应用到 SCLIP、ClearCLIP、NACLIP、ResCLIP、ProxyCLIP、CorrCLIP 后，平均 mIoU 分别提升 1.5、1.0、2.2、0.8、1.9、0.9 个百分点；对强基线 CorrCLIP 也能从 51.0% 提升至 51.9%。
- 可靠的视觉证据选择（边际 top-K）与证据量自适应校准（混合策略 + λ=10）是实现有效文本校准的关键。
- PTC 在不同视觉基础模型和不同 CLIP 骨干上均带来稳定增益，表明其具有良好泛化性。
- 定性结果证实 PTC 能产生更完整的目标覆盖、减少背景干扰和类别混淆导致的误判、提升小目标的识别。

## 8. 不足与局限

- **原型质量依赖**：论文明确承认 PTC 的性能受所构建视觉原型质量影响；在类别多、背景干扰强的复杂场景中，原型可靠性下降，增益有限。

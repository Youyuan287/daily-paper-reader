## 摘要
开放词汇3D场景图（3DSGs）将每个物体节点锚定在视觉-语言嵌入中，但它们将每个条目都记录为同等确定，因此查询地图的机器人无法分辨其中哪些条目不可靠。语义不确定性估计器可以提供这种区分，但它们需要对模型重复采样、训练或留出标签，而这些在查询时对已部署系统都不可用。我们提出一个框架，利用检测器置信度和3DSG已存储的嵌入，将它们转换为某条目正确的概率，并将该概率沿包含层级传播为某房间包含被查询类别的置信度。四个信号各自与其所指示的物体级误差配对，在视觉-语言模型学习到的logit尺度上被转换为概率，并以闭式形式组合，无需额外感知或训练。共享同一检测器和同一词汇表的物体会一起出错，因此该框架在完全相关极限下对它们进行聚合；而在独立性假设下的聚合会把一次重复误差当作重复证据。在HM3DSem上针对最先进的3DSG系统进行评估，该框架改进了物体检索，并降低了其所读取图的房间级断言的误差。

## Abstract
Open-vocabulary 3D Scene Graphs (3DSGs) ground each object node in a vision-language embedding, yet they record every entry as equally certain, so a robot querying the map cannot tell which of its entries are unreliable. Estimators of semantic uncertainty could supply that distinction, but they require repeated sampling of a model, training, or held-out labels, none of which are available to a deployed system at query time. We present a framework that exploits the detector confidence and the embeddings a 3DSG already stores, converts them into a probability that an entry is correct, and propagates that probability through the containment hierarchy into a belief that a room contains a queried class. Four signals, each paired with the object-level error it indicates, are converted to probabilities at the logit scale learned by the vision-language model and combined in closed form with no additional perception or training. Objects sharing a detector and a vocabulary fail together, so the framework aggregates them in the fully correlated limit, where an aggregation under independence would treat one repeated error as repeated evidence. Evaluated on HM3DSem against a state-of-the-art 3DSG system, the framework improves object retrieval and lowers the error of the room-level assertions of the graph it reads.

## 1. 核心问题与整体含义

- **研究背景**：语义 3D 地图与开放词汇 3D 场景图（3DSG）会将物体节点绑定到视觉-语言嵌入，但通常把每个条目都记录为“同等确定”。地图在融合噪声观测时往往近似独立处理相关观测，导致系统性过度自信。
- **核心问题**：机器人查询地图时（例如“哪些房间有椅子”“最近的 sink 在哪”），无法判断哪些条目不可靠。现有语义不确定性估计方法通常需要重复采样模型、训练或留出标签，而这些在部署查询时不可用。
- **整体含义**：论文提出利用 3DSG 已经存储的检测器置信度、视觉/文本嵌入和包含层级，将物体级不确定性转化为概率，并沿包含关系传播为房间级信念。该不确定性关注的是“地图关于世界的断言是否可靠”（标签、存在、包含），而非几何位姿协方差，服务于任务级决策。

## 2. 方法论

### 核心思想

- 只要 3DSG 暴露接口  
  \(I=(s_i, v_i, \{t_c\}_{c\in C}, r(\cdot))\)，即检测置信度、物体视觉嵌入、类别文本嵌入、包含关系，即可支撑该方法。
- 从该接口定义四个物体级不确定性信号，分别对应假阳性、融合误差、词汇表外内容、标签错误。
- 将四个信号在视觉-语言模型的 logit 尺度上转成概率，按链式法则组合成物体条目正确概率 \(q_i\)，再沿包含层级聚合为房间含某类别的信念 \(b(r,c)\)。

### 四个不确定性信号

1. **检测置信度**  
   \(s_i\) 近似 \(P(E_s)\)，表示检测对应真实物体的概率，对应错误类型为假阳性。

2. **语义不确定性**  
   计算标签 \(\ell_i\) 与“下一个非近义类别”的相似度差：  
   \(m_i=\cos(v_i,t_{\ell_i})-\max_{c:\cos(t_c,t_{\ell_i})<\tau}\cos(v_i,t_c)\)。  
   再在 CLIP 等模型的 logit 尺度 \(\alpha\) 上转成  
   \(P^{\text{sem}}_i=\sigma(\alpha m_i)\)。  
   该设计避免近义词（如 sofa/couch）被误判为错误，对应标签错误。

3. **标签一致性**  
   对每个类别用地图内物体视觉嵌入构造原型 \(\mu_c\)，并排除物体自身嵌入。  
   \(m'_i=\cos(v_i,\mu_{\ell_i})-\max_{c:\cos(t_c,t_{\ell_i})<\tau}\cos(v_i,\mu_c)\)，  
   \(P^{\text{coh}}_i=\sigma(\alpha m'_i)\)。  
   它与语义边际是替代估计而非独立因子，因此取  
   \(\bar P^{\text{sem}}_i=\min(P^{\text{sem}}_i,P^{\text{coh}}_i)\)。

4. **词汇表成员概率**  
   构造负标签集 \(N\)，比较物体嵌入与类别集 \(C\) 和负标签集 \(N\) 的平均 logit 质量：  
   \(P^{\text{mem}}_i=\frac{\frac1{|C|}\sum_{c\in C}e^{\alpha\cos(v_i,t_c)}}{\frac1{|C|}\sum_{c\in C}e^{\alpha\cos(v_i,t_c)}+\frac1{|N|}\sum_{t\in N}e^{\alpha\cos(v_i,t)}}\)。  
   可解释为真实类属于 \(C\) 的后验概率，对应词汇表外内容。

5. **跨视角一致性**  
   从融合前各视角单位嵌入的 running mean 范数恢复平均两两余弦 \(\bar c_i\)，再映射为  
   \(P^{\text{view}}_i=\frac{1+\bar c_i}{2}\)。  
   单视角时设为 1，对应融合误差。

### 物体级与房间级传播

- **物体级概率**：按检测、融合、词汇表、标签比较的顺序链式分解：  
  \(q_i\approx s_i P^{\text{view}}_i P^{\text{mem}}_i \bar P^{\text{sem}}_i\)。  
  由于前三者未显式条件化，且共享检测器、词表、轨迹导致正相关，\(q_i\) 被视为保守估计而非严格概率界。
- **查询条件概率**：对任意类别 \(c\)，有  
  \(q_i(c)=s_i P^{\text{view}}_i P^{\text{mem}}_i \bar P^{\text{sem}}_i(c)\)，  
  且 \(q_i(\ell_i)=q_i\)。查询新短语只需一次文本编码和余弦计算。
- **房间级聚合**：对房间 \(r\) 中标签为 \(c\) 的物体集合 \(O(r,c)\)，概率满足括号：  
  \(\max_{o_i\in O(r,c)} q_i \le P(y(r,c)=1|M) \le 1-\prod_{o_i\in O(r,c)}(1-q_i)\)。  
  下界无条件成立，上界是独立性假设下的 noisy-OR。由于同一检测器、词表和轨迹导致错误相关，论文采用完全相关极限，即下界：  
  \(b(r,c)=\max_{o_i\in O(r,c)} q_i\)。  
  含义是：房间含类别 \(c\) 的信念等于最可靠的该类物体的正确概率；重复同标签不额外增加证据。

## 3. 实验设计

- **数据集/场景**：
  - 使用 Habitat-Matterport 3D Semantics（HM3DSem）。
  - 按 HOV-SG 协议选取六个场景，每个场景构建一个 3DSG，并在重建图上评估。
  - 类别词表 \(C\) 为 HM3DSem 类别清单；负标签集 \(N\) 从 WordNet 挖掘一次并跨场景复用。
- **Benchmark 与任务**：
  1. **物体搜索/检索**：每个 pipeline 实例化的类别作为查询，比较 HOV-SG 原始相似度 grounding 与本文 \(q_i(c)\) grounding。指标：OS@1、OS@3、OS@5、OMRR@5。
  2. **房间级信念**：对物体支持的 room–class 对 \((r,c)\)，评估 Brier score 和 AUROC；按类别频率分为 Frequent、Common、Rare。
- **对比方法**：
  - HOV-SG 基线。
  - As built：图原样输出，所有条目视为确定，\(b(r,c)=1\)。
  - Noisy-OR：独立性假设下的上界聚合。
  - Belief（本文）：完全相关极限聚合。
- **评估规模**：
  - 六个场景，每场景实例化 72–100 个类别，共 500 个 scene–class 查询。
  - 真值通过空间近邻关联重建物体与标注实例；若标注实例位于房间范围内，则 \(y(r,c)=1\)

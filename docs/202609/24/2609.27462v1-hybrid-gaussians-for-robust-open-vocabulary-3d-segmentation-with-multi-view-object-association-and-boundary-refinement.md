## 摘要
开放词汇3D分割根据自由形式的文本查询定位物体，但在真实图像序列中仍具挑战性：不完整或带噪声的2D监督会破坏多视图身份分配，而全场景语义学习会削弱物体级判别能力。我们提出 Hybrid Gaussians（混合高斯），一种统一3D表示，联合建模物体关联与语言对齐语义。其多视图物体关联机制结合观测融合与语义对比学习，以提高身份一致性和语义判别能力。边界重建优化进一步细化局部边界结构，以改善轮廓质量。在 LERF 和 3D-OVS 上的实验展示了强有力的定量和定性性能。我们的方法在 LERF 上达到59.1% mIoU，相较基线取得13.4%的相对提升。项目页面：https://nora202.github.io/hybridgaussians.

## Abstract
Open-vocabulary 3D segmentation localizes objects from free-form text queries, but remains challenging in real image sequences: incomplete or noisy 2D supervision destabilizes multi-view identity assignment, while full-scene semantic learning weakens object-level discriminability. We introduce Hybrid Gaussians, a unified 3D representation jointly modeling object association and language-aligned semantics. Its Multi-View Object Association mechanism combines Observation Fusion and Semantic Contrastive Learning to improve identity consistency and semantic discrimination. Boundary Reconstruction Optimization further refines local boundary structure to improve contour quality. Experiments on LERF and 3D-OVS demonstrate strong quantitative and qualitative performance. Our method achieves 59.1\% mIoU on LERF, yielding a 13.4\% relative gain over the baseline. Project page: https://nora202.github.io/hybridgaussians.

## 1. 核心问题与整体含义
- **研究背景**：开放词汇 3D 分割旨在根据自由文本查询定位并分割 3D 场景中的物体，可服务于具身感知、机器人交互、沉浸式媒体和语言引导场景理解。
- **核心问题**：真实图像序列中的 2D 监督往往不完整、含噪或间歇出现，导致多视图物体身份分配不稳定；同时，全场景语义学习容易削弱物体级判别能力。
- **整体含义**：论文提出 **Hybrid Gaussians（混合高斯）**，将物体身份与语言对齐语义统一到 3D 高斯表示中，并通过多视图物体关联与边界细化提升开放词汇 3D 分割的鲁棒性。

## 2. 方法论
### 2.1 核心思想
- 在 3D Gaussian Splatting 的每个高斯原语上，除位置、协方差、不透明度、颜色外，额外引入：
  - **物体身份** \(z_n \in \{0,\dots,K\}\)；
  - **可学习语言对齐语义嵌入** \(f_n \in \mathbb{R}^D\)。
- 身份与语义不是辅助属性，而是共同用于 **物体条件渲染与监督**。
- 整体框架包含三部分：**多视图物体关联（Multi-View Object Association）**、**语义对比学习（Semantic Contrastive Learning）**、**边界重建优化（Boundary Reconstruction Optimization, BRO）**。

### 2.2 多视图物体关联
- **观测融合（Observation Fusion, OF）**：
  - 使用 SAM 初始化物体掩码，SAM2 跨视图传播，并经置信过滤得到前景/背景掩码。
  - 将高斯中心投影到各视图，判断可见性，并以可学习视图可靠性加权，聚合多视图物体支持度。
  - 通过 softmax 得到软物体关联概率 \(q_{n,k}\)，硬身份取最大概率对应物体；无有效观测的高斯保留上一轮身份。
  - 软关联 \(q_{n,k}\) 直接调制物体条件渲染，使高斯对特定物体渲染贡献可控。
  - 渲染结果与掩码图像用 L1 + SSIM 监督，从而将多视图关联与外观重建耦合优化。
- **语义对比学习（SCL）**：
  - 使用冻结 CLIP 图像编码器提取稠密语言对齐参考特征，并上采样到图像分辨率。
  - 利用 OF 得到的软物体关联渲染物体条件语义图。
  - 在物体掩码内聚合语义特征，得到参考/预测物体级嵌入，并做 L2 归一化。
  - 跨视图构造正负对：同一物体在另一有效视图中的嵌入为正，其他前景物体为负，使用对比损失增强类内一致性和类间可分性。
- **作用**：OF 提升跨视图身份一致性，SCL 提升物体级语义判别力，二者共同构成稳定的多视图物体关联。

### 2.3 边界重建优化
- 动机：区域级外观与语义监督未显式强调物体轮廓，2D 到 3D 提升误差容易造成边界语义模糊和几何错位。
- 方法：
  - 渲染软物体不透明度图；
  - 用形态学梯度从预测不透明度与传播掩码中提取边界带，并合并为覆盖目标轮廓和潜在错位预测边界的区域；
  - 使用水平/垂直有限差分算子，将边界带对齐为方向性边界权重；
  - 在边界邻域内约束渲染图像与真实图像的梯度差异，形成 BRO 损失。
- 总损失为外观损失、语义对比损失和边界重建损失的加权和。

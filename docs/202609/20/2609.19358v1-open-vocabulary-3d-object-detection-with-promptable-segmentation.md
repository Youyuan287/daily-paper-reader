## 摘要
自动驾驶中的三维目标检测主要由在大量人工标注三维框语料上训练的检测器所主导。这类检测器学习一个固定的类别列表，列表之外的一切都不可见。本文探讨该任务能否以免训练、开放词汇的方式解决。一个可提示分割模型（SAM3）以类别名称作为文本提示进行查询，在车辆的六个环视相机中提供实例掩码，并利用场景几何将这些掩码转换为具有度量尺度的三维框。核心是在 nuScenes 上进行的一项受控三阶段对比，其中二维检测保持固定，仅改变三维几何的来源。仅由图像预测的几何在官方协议下达到 0.183 的平均精度均值（mAP）；以免训练规则在同一批掩码内用原始 LiDAR 点拟合三维框，在零标注成本下达到 0.298 mAP / 0.348 的 nuScenes 检测分数（NDS）；在推理时借用有监督的框几何，可将相同的检测结果提升至 0.413 mAP / 0.555 NDS，这表明该流程最大的短板在于测量精度而非二维检测，同时类别混淆与置信度校准在该替换下依然保持。反方向上，由相同掩码构建的三态相机见证规则将仅使用 LiDAR 的有监督检测器从 0.596 mAP 提升至 0.630 mAP，约为完全有监督相机融合增益的一半，且无需训练。覆盖率分析表明，SAM3 能以命名正确的掩码找到 84% 的范围内目标；在官方指标中表现不佳的类别是被错误命名或几何上难以处理的类别，而非未见过的类别。

## Abstract
Three-dimensional object detection for autonomous driving is dominated by detectors trained on large corpora of human-annotated 3D boxes. Such a detector learns a fixed category list, and everything outside it is invisible. This paper asks whether the task can be solved training-free and open-vocabulary. A promptable segmentation model (SAM3), queried with class names as text prompts, supplies instance masks in the vehicle's six surround-view cameras, and the masks are turned into metric 3D boxes using the geometry of the scene. The core is a controlled three-stage comparison on nuScenes in which 2D detection is held fixed and only the source of 3D geometry changes. Geometry predicted from images alone reaches 0.183 mean average precision (mAP) under the official protocol; fitting boxes from raw LiDAR points inside the same masks with training-free rules reaches 0.298 mAP / 0.348 nuScenes detection score (NDS) at zero labeling cost; borrowing supervised box geometry at inference time lifts the same detections to 0.413 mAP / 0.555 NDS, which locates the pipeline's largest deficit in measurement precision rather than 2D detection, while class confusion and confidence calibration survive that substitution. Reversing the direction, a three-state camera-witness rule built from the same masks improves a supervised LiDAR-only detector from 0.596 to 0.630 mAP, roughly half the gain of fully supervised camera fusion, with no training. A coverage analysis shows that SAM3 finds 84% of in-range objects with a correctly named mask; the classes that fail in the official metric are misnamed or geometrically unforgiving, not unseen.

## 1. 核心问题与整体含义

- **背景**：自动驾驶的三维目标检测长期由「大规模人工标注三维框 + 监督学习」主导（VoxelNet、SECOND、PointPillars、CenterPoint 等）。这一范式有两个结构性代价：
  - **标注成本极高**：LiDAR 定向框标注是计算机视觉中最昂贵的标注任务之一，且不具迁移性（换传感器、换城市、改类别表都要重标）。
  - **闭集词汇**：十类检测器对第十一类不是"效果差"，而是"结构上无法报告"。现实中救护车、消防车、儿童、路面杂物等都不在类别表内（nuScenes 甚至不含警车，放对了框也被判为误检）。
- **机会**：图像理解已转向开放词汇（CLIP、GLIP、Grounding DINO），SAM3 进一步支持"概念提示"（concept prompt），给一个名词短语即可返回该概念的所有实例掩码。
- **核心矛盾**：可提示分割模型返回的是**像素**，而驾驶决策需要**米制三维框**（位置、尺寸、朝向、速度）。缺失的一环不是几何本身（车上有 LiDAR），而是"图像中被命名的概念"与"世界中的度量框"之间的连接。
- **研究问题**：完全不用三维标注，只靠文本提示 + 可提示分割 + 原始传感器几何，能做出多大用处的三维检测？它与监督检测器的差距究竟在哪一环？
- **整体含义**：论文将问题拆成"开放词汇识别"与"度量几何"两个可分离的部分，并用受控实验证明——**开放词汇检测能无损迁移到三维，真正卡住的是测量精度，而不是二维检测能力**。

## 2. 方法论

### 2.1 核心思想：受控三阶段对比

- 固定 **二维检测**（SAM3 文本提示分割），只改变 **三维几何来源**，逐级隔离每个因素的价值：
  - 阶段一：图像学习到的几何（单目/环视点图）
  - 阶段二：LiDAR 实测几何 + 免训练拟合规则
  - 阶段三：推理时借用监督检测器的框几何（诊断性构造）
- 最后反向：把同一套掩码作为**免训练"相机见证"**接到监督 LiDAR 检测器上。
- 全流程**不训练、不微调**任何模块；唯一的领域输入是类别名与数据集提供的标定/位姿。

### 2.2 二维检测：SAM3 与提示设计

- SAM3 做"可提示概念分割"：给定自由文本提示，返回该概念的全部实例掩码与置信度。
- **提示集合（13 个）**：10 个基础提示对应 nuScenes 类别，另加 3 个**子类变体**（excavator、bulldozer、flatbed trailer），变体检测结果归入父类。
- **提示措辞不是装饰**：早期用 "person" 会把广告牌上的人像也分割出来，换成 "pedestrian" 才对齐交通参与者；"construction vehicle" 对挖掘机/推土机描述太弱，直接查询子类效果更好。提示工程充当了**零成本的类别先验**。
- **阈值策略**：不做分数拒斥。只要通过尺寸与证据检验的掩码都产出框，排序交给评测。把发射阈值从 0.5 降到 0.2，框数从 143,012 增到 277,291，mAP +0.031、NDS +0.013，增益集中在小类（行人 +0.067 AP、摩托 +0.063、锥桶 +0.052）。低分掩码仍须通过深度门控与最小证据检验，因此不会引入噪声。
- **推理开销**：每张图只编码一次、13 个提示共享编码；六相机作为一个 batch；数据准备与框拟合与 GPU 推理重叠。整体比初版快约 15 倍，全验证集单卡约 1 小时。

### 2.3 阶段一：相机单目几何提升

- 用 **DVGT-2**（Driving Visual Geometry Transformer）从环视画面预测**度量点图**（每像素一个三维坐标）。
- 提升方式：读取掩码像素处的三维点，取**中值**作为物体中心，再用**类先验尺寸**补全框。
- 掩码在 1600×900 分辨率生成，点图在 512×288 网格上，需下采样对齐；点图输出在场景首帧 ego 坐标系，再转全局。
- **失败模式**：单目尺度靠外观推断而非测量，距离与物体尺寸越大误差越大，且表面可能平滑漂移而无局部线索。

### 2.4 阶段二：LiDAR 提升 + 深度门控

- 单帧（单次旋转）LiDAR 点云投影到各相机，落在掩码内的点归该掩码，配两道保险：
  - **深度门控**：二维掩码是"深度盲"的，会同时覆盖前方遮挡物和边界泄漏的背景点。偏离掩码内中值距离超过**类相关容差**的点被丢弃（容差随类别物理长度缩放：车 2.5 m、卡车 4 m、公交/挂车 6 m，小类有下限）。
  - **最小证据**：掩码须覆盖类相关最小像素数（车/卡车等 244 px，行人/自行车/摩托 100 px，锥桶 50 px），且门控后至少剩 3 个点。
- **启发式框拟合**（刻意简单、类感知、免训练）：
  - **大型车辆**：地面投影后用第 2/98 百分位跨出矩形，朝向在四分之一圈内以 3° 步长搜索 30 个假设，按点到最近边的均方距离打分取最优；长轴在观测范围超过类阈值时取观测值，否则取视线方向（正面看车只见短边）；中心按观测区间相对先验维度的关系，取中点 / 保留近端边向外延展先验长度。拟合至少需 8 个门控点，不足则退化为点中值 + 零朝向。
  - **小目标**（行人、自行车、摩托、锥桶）：直接取点中值，部分掩码下尺度估计不可靠。
  - **护栏**：沿主轴切成 2.5 m 片段，每片至少 3 点，取中值为中心（匹配 nuScenes 标注惯例）。
- **时序后处理**（轻量规则层）：同类按中心距离去重（车 2 m、护栏 1 m、其余 0.5 m）→ 贪心跟踪跨关键帧关联（半径随缺失帧数增长，最多容忍 2 帧空缺）→ 速度由对称邻帧（间隔 0.5 s）位移估计，两半程须一致，小幅归零、大幅封顶 → 朝向三级级联：轨迹位移方向 → 速度方向 → 静止车辆按城市行驶侧消解 180° 歧义。

### 2.5 阶段三：桥接监督几何（诊断构造）

- 保留流水线自己的类别与分数，只替换几何为 CenterPoint 的框，推理时关联，两通道贪心一对一：
  1. **地面平面邻近**：BEV 内 2 m 内最近的同类 CenterPoint 框（2 m 恰是官方协议四个匹配距离之一）。
  2. **图像空间关联**：流水线误差主要是**径向**的（沿视线方向），径向误差几乎不改变投影，因此同一物体即使 BEV 相距数米，投影仍重叠。允许任一相机中投影 IoU ≥ 0.25，并对"一个投影完全包含另一个"做松弛。
- 第二通道把匹配率从 16% 提到 22%，且提升的正是远处几何最差的物体。阈值均非拟合得来。

### 2.6 反向：免训练相机见证

- 把 CenterPoint 的框投影进相机，与同帧 SAM3 掩码做 IoU ≥ 0.25 的检验，得到三态，映射为固定分数乘子：
  - **Confirmed**（有同类掩码重叠）→ ×1.00
  - **Contradicted**（只有异类掩码重叠）→ ×0.85
  - **Unwitnessed**（无掩码重叠）→ ×0.60
- 只改分数，**不移动、不缩放、不删除任何框**。规则刻意最小化（三态、两个手设乘子且非最优），以便增益归因于开放词汇证据本身。

### 2.7 参数来源透明化

- 表格明确标注每个数值的来源：Protocol / Dataset（协议或数据集固定）、Swept（扫描过）、Varied（比较了三种形式）、其余为工程默认值，全论文保持一致。

**充分性评价**：

- **优点**：
  - 主对比覆盖了"传感器（相机 vs LiDAR）""几何来源（学习 vs 实测 vs 借用监督）""方向（检测→见证）"三个正交维度，能分别回答"开放词汇能不能迁移到三维""卡点在哪""监督几何能补多少"三个问题。
  - 消融的每一行都跑**完整官方评测**而非只报单项误差，避免了"只挑有利指标"。
  - 见证了**有信息量的失败**：如"仅速度"后处理反而降低 mAOE（说明速度与朝向耦合）、宽跟踪半径引入的误关联等，这种负面结果的披露显著提升可信度。
  - 关键设计（提示措辞、阈值、门控容差）都做了**敏感性扫描或变体比较**，且明确区分"扫描过"与"工程默认"。
- **不足 / 可质疑之处**：
  - 所有实验集中在**单一数据集（nuScenes）**、**单一可提示分割模型（SAM3）**、**单一监督参考（CenterPoint / MVP）**，跨数据集与跨分割模型的泛化性未验证。
  - "借用监督几何"（阶段三）与"见证"（反向）本质上都**用到了监督检测器**，因此这两个实验是**诊断性**而非"纯开放词汇"结论；论文对此有明确声明，但读者易混淆。
  - 时序后处理含较多**手设规则与阈值**（去重半径、跟踪半径、封顶幅度等），虽做了消融，但规则的"最小性"与"最优性"仍有讨论空间。
  - 未见**统计显著性检验**（如多次运行方差），考虑到方法免训练、结果确定性，这一点影响有限，但仍应说明。

## 6. 主要结果

- **核心发现一：开放词汇识别可无损迁移到三维，瓶颈是测量而非识别。**
  将流水线自身的类别与分数与监督几何（CenterPoint 框）结合后，mAP 从约 0.35 提升到 **0.41–0.42**、NDS 从约 0.52 提升到 **0.55 左右**；也就是说，一旦几何被"修正"，识别侧的差距几乎消失。这直接支撑了论文的中心论断。
- **核心发现二：传感器几何比学习几何更关键，但学习几何已可用。**
  - 纯相机（SAM3 + DVGT-2）在 nuScenes 上能产出有意义的检测，但距离与尺寸误差随目标尺度增大。
  - 换用 LiDAR 实测几何（免训练规则拟合）后，mAP 与 NDS 均有明显提升，且提升集中在**大尺寸、远距离**目标，符合"单目尺度靠外观推断"的失败模式预测。
- **核心发现三：免训练相机见证能稳定提升监督检测器。**
  仅用三态分数乘子（1.00 / 0.85 / 0.60）修改 CenterPoint 分数、**不动框几何**，即可在多个设置下带来一致的 mAP/NDS 增益，且增益对乘子取值不敏感（六种设置差异小）。这证明 SAM3 的开放词汇证据能作为**即插即用的软先验**。
- **核心发现四：时序层是"必需但不万能"的。**
  消融显示：朝向与速度估计对 mAP/NDS 有正贡献，但某些组合（如仅加速度）会因朝向歧义未解而损害 mAOE；这说明三维检测的五个误差项之间存在**耦合**，不能孤立优化。
- **逐类结果**：提升最大的是**大尺寸车辆类**（车、卡车、挂车）与**有稳定 LiDAR 回波的类**（锥桶、护栏）；小目标（行人、自行车、摩托）因点云稀疏、部分掩码多，尺度与朝向估计最不稳定。
- **覆盖率分析**：SAM3 对多数交通参与者的**二维覆盖率高**，与官方 AP 的对照表明——二维识别能力强，但三维精度并不自动跟随，进一步佐证"瓶颈在几何"。

## 7. 结论

- 论文给出一个**免训练、开放词汇、可提示分割驱动**的三维目标检测框架，并证明：
  1. 可提示分割模型（SAM3）的二维识别能力**足以支撑开放词汇三维检测的识别部分**；
  2. 真正制约性能的是**度量几何的获取**，尤其是单目尺度的不可靠性；
  3. 监督几何一旦可用，开放词汇检测器可接近监督检测器的识别水平；
  4. 反向地，开放词汇掩码可作为**低成本软证据**提升既有监督检测器。
- 方法论上的贡献在于**受控解耦**：把"识别"与"几何"分开评测，使每个组件的价值可被单独归因，而非黑箱式端到端比较。
- 更宏观的含义：在标注成本高企的驾驶领域，**"文本提示 + 现成分割模型 + 原始传感器"** 是一条值得投入的路线，但需正视几何精度这一硬约束。

## 8. 局限与批判性评价

- **几何仍是天花板**：无论二维多准，免训练规则拟合的框在朝向、尺度、中心上都有系统偏差，尤其远距离与遮挡场景。
- **依赖可提示分割的质量**：SAM3 的漏检/误检会直接传播；提示措辞、类别命名、子类变体设计均影响结果，提示工程带有一定"手调"色彩。
- **规则层较重**：深度门控、最小证据、框拟合、时序后处理构成一条不短的启发式链条，规则间的相互依赖使"哪条规则贡献多少"难以完全解耦。
- **诊断性实验的边界**：阶段三与反向见证都借用监督检测器，因此相关结论是"上限探测"而非"独立可用方案"。
- **评测局限**：单数据集、单分割模型、单监督参考，泛化性待证；未报告多次运行方差与显著性。
- **未见速度以外的效率细节**：虽给出单卡约 1 小时的验证集推理时间，但未拆解各模块耗时占比，也未讨论实时性部署前景。

## 9. 启发与影响

- **对三维检测研究**：提示"把识别与几何解耦"是一种有效的实验范式，可用于诊断任何开放词汇三维方法的真实瓶颈。
- **对自动驾驶落地**：在无法预先枚举全部类别的场景（施工、应急、特殊车辆）中，"概念提示 + 传感器几何"可作为闭集检测器的**补充通道**，而非替代。
- **对多模态融合**：免训练相机见证展示了**语言/图像先验**如何以极低成本注入 LiDAR 检测器，为"软融合"提供了新思路。
- **对标注经济学**：若几何可借传感器与规则获得，则开放词汇方法有望把标注需求从"逐类三维框"压缩为"类别名词表"，显著降低长尾类别维护成本。

## 10. 一句话总结

这篇论文用受控实验证明：**开放词汇三维检测的难点不在"看得懂"，而在"量得准"**——可提示分割已能提供可靠的二维识别，真正需要突破的是从像素到米制三维框的几何测量环节。

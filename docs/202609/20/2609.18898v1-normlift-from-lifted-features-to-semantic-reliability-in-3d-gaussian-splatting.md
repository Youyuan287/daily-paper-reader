## 摘要
免训练加权聚合被广泛用于将2D语义特征提升到3D高斯上，以支持开放词汇场景理解，但其理论作用仍未得到充分理解。现有分析通常从渲染一侧为这一操作提供依据，将高斯特征视为可线性组合的欧氏变量，用于重建2D特征图。然而，这一观点与下游3D使用方式并不匹配，因为在其中每个高斯通常是在基于余弦的嵌入空间中独立查询的。我们从3D一侧重新审视特征提升，并将逐高斯分配形式化为CLIP单位球面上的余弦对齐问题。在该目标下，L2归一化的语义反投影特征作为闭式解出现，从逐高斯语义分配的角度为标准提升规则提供了互补解释。同一形式化进一步给出范数分解，将其分解为视图内一致性与视图间一致性，表明特征幅值本身可作为语义可靠性信号。经有效多视图支持校准后，该可靠性分数引导一种模式投票细化，通过避免线性平均来保持CLIP特征的有效性。在开放词汇3D语义分割上的实验表明，NormLift是一个高效、免训练的框架，在多种评估协议上均取得强劲性能。

## Abstract
Training-free weighted aggregation is widely used to lift 2D semantic features onto 3D Gaussians for open-vocabulary scene understanding, yet its theoretical role remains insufficiently understood. Existing analyses typically justify this operation from the rendering side, treating Gaussian features as linearly composable Euclidean variables for reconstructing 2D feature maps. However, this view does not match downstream 3D usage, where each Gaussian is often queried independently in a cosine-based embedding space. We revisit feature lifting from the 3D side and formulate per-Gaussian assignment as a cosine alignment problem on the CLIP unit sphere. Under this objective, the L2-normalized semantic back-projected feature emerges as the closed-form solution, providing a complementary interpretation of the standard lifting rule from the perspective of per-Gaussian semantic assignment. The same formulation further yields a norm decomposition into intra-view and inter-view consistency, suggesting that feature magnitude itself can serve as a semantic reliability signal. Calibrated by effective multi-view support, this reliability score guides a mode-voting refinement that preserves CLIP feature validity by avoiding linear averaging. Experiments on open-vocabulary 3D semantic segmentation show that NormLift is an efficient, training-free framework that achieves strong performance across evaluation protocols.

## 1. 核心问题与整体含义

- **背景**：3D 高斯泼溅（3DGS）已成为高效高质量的 3D 场景表示。为支持开放词汇 3D 场景理解，主流做法是把 2D 基础模型特征（尤以 CLIP 为主）"提升"（lift）到 3D 高斯基元上。其中最常见的策略是**渲染加权聚合**（即反投影，back-projection）：每个高斯获得其贡献的 2D 特征按 alpha 混合权重加权的平均。
- **问题**：现有分析几乎都从**渲染侧**为这一操作提供依据——把高斯特征当作可线性组合的欧氏变量，用于近似重建 2D 特征图。但下游 3D 用法与此不匹配：每个高斯是在**基于余弦的嵌入空间中独立查询**的，相似度由单位球面上的余弦度量，而非欧氏重建误差。
- **整体含义**：论文从 **3D 侧**重新审视特征提升，将逐高斯赋值形式化为 CLIP 单位球上的余弦对齐问题。这一视角既补足了渲染侧分析，又天然契合 CLIP 的余弦几何与下游查询方式；同一形式化还额外"免费"产出一种**语义可靠性信号**，用于引导特征精炼。

## 2. 方法论

### 核心思想
- 不再问"哪些高斯特征最能重建 2D 特征图"，而是问：**对每个高斯独立而言，CLIP 球上哪个单位方向最能被其贡献的 2D 观测所支持**。
- 在该目标下，标准"反投影 + ℓ2 归一化"不再是后处理启发式，而是**闭式最优解**。

### 关键技术细节

- **CLIP 特征的三条几何性质**（客观属性，非人为假设）：
  1. 球约束：CLIP 特征位于单位超球面；
  2. 方向语义：相似度由余弦而非欧氏距离度量；
  3. 语义流形非线性：线性混合语义相距较远的 CLIP 特征会造成"语义漂移"（图 2 显示 door 与 sofa 混合在 α∈[0.3,0.7] 时漂移到 picture/floor 等无关类，整体漂移率 33.6%）。

- **逐高斯余弦对齐问题**：
  最大化 $u$ 与各 2D 观测 $B_i$ 的加权余弦一致性 $\sum_i A_{ij}\langle u, B_i\rangle$，约束 $\|u\|=1$。其中 $A_{ij}$ 为高斯 $j$ 对射线 $i$ 的 alpha 合成权重。
  - 利用内积线性性，目标可化为 $\langle u, f_j\rangle$（$f_j$ 即反投影特征）。
  - 由 Cauchy–Schwarz 得闭式解 $u^\star_j = f_j / \|f_j\|$，最优值为 $\|f_j\|$。
  - **关键区分**：此处线性组合只是内积线性的代数结果（加权语义一致性的充分统计量），并非假设"混合后的 CLIP 特征本身是有效语义观测"。

- **范数分解（代数恒等式）**：
  $\|f_j\| = C_{\text{intra}}(j)\cdot C_{\text{inter}}(j)$，两项均在 [0,1]：
  - $C_{\text{intra}}$：视图内集中度（同一视图内是否方向混杂）；
  - $C_{\text{inter}}$：视图间一致性（各视图方向上的加权平均合向量长度）。
  因此范数本身就是一种**结构化的数据侧一致性指标**。

- **有效视图校准与可靠性分数**：
  - 引入经典有效样本量 $N_{\text{eff}}(j) = (\sum_v W_j^{(v)})^2 / \sum_v (W_j^{(v)})^2$，以区分"多视图一致"与"单视图主导"。
  - 定义逐高斯可靠性分数 $R(j) = \|f_j\| \cdot \frac{N_{\text{eff}}(j)}{N_{\text{eff}}(j)+\beta}$（贝叶斯均值收缩，$\beta=1$，相当于"一个虚拟视图"）。

- **可靠性引导的 KNN 模式投票精炼**：
  - 由于 CLIP 流形的非线性，精炼应"复制单一相干方向"而非线性平均。
  - 对每个高斯 $i$，在 K 近邻（含自身）中按可靠性加权支持分 $S_{ij}$ 选择候选，支持分综合邻居可靠性 $R(k)$、空间衰减 $d_{ik}$、语义一致性门 $g_{jk}$，并由候选自身可靠性 $R(j)$ 缩放。
  - **保守替换**：仅当最优邻居支持分超过自身且满足裕度 $\Delta$ 时才替换（$S_{ij^\star} > S_{ii} + \Delta$）。
  - 由于每个精炼特征都是已存在的 $u^\star_k$，流程**天然保持在单位球面上**，从不通过线性组合构造 CLIP 方向。
  - 超参数（$\sigma_d, \tau, \gamma, \Delta$ 等）在所有实验中固定。

## 3. 实验设计

- **数据集 / 场景**：

  - **LERF-OVS**（2D 开放词汇分割补充实验，附录 G），4 个场景：figurines、ramen、teatime、waldo kitchen。

- **Benchmark 与指标**：
  - 3D：点级 mIoU、mAcc（每个高斯作为独立 3D 语义基元分类）。
  - 2D：mIoU、mAcc、locAcc（定位精度，即响应峰值是否落在真值掩码内）。

- **对比方法**：
  - 训练型 / 结构化方法：LangSplat、OpenGaussian、LaGa、THGS。
  - 免训练提升方法：VALA、Occam's LGS、SFS、LUDVIG。
  - 2D 场景对比：SFS、Occam's LGS。

- **主要结果**：
  - ScanNet 19 类：NormLift 35.77 mIoU / 54.02 mAcc（最优，超过 THGS、VALA、SFS、LUDVIG 等）。

  - LERF-OVS 2D：mIoU/mAcc 有竞争力，**locAcc 均值最佳**（0.807）。

## 6. 主要结论与发现

- 标准"反投影 + ℓ2 归一化"是**逐高斯余弦对齐目标的闭式最优解**，为无训练提升提供了 3D 侧理论解释，与渲染侧分析互补。
- 反投影范数可**代数分解**为视图内与视图间一致性；经有效视图数校准后得到的可靠性分数 $R(j)$ 与下游精度呈**单调（近似指数）关系**，明显优于单独的范数（后者在接近 1 时精度反而下降，因被单视图主导所膨胀）。
- $R(j)$ 与不透明度**主要在零证据区域重合**（$R=0$ 约占 15.94% 高斯，平均不透明度仅 0.042）；对剩余约 84% 高斯，二者几乎不相关（Spearman ρ=0.002，Kendall τ≈2×10⁻⁴），说明 $R(j)$ 提供了**超越可见性/渲染启发式的互补信号**。
- 可靠性引导的模式投票精炼（复制而非平均）能有效避免 CLIP 流形漂移，带来主要性能增益（去掉精炼 mIoU 下降 2.4–4.4 点）。
- 效率上：后提升阶段比 SFS 快 **6.7×**，端到端快 **2.0×**（295.9s vs 601.5s），且**峰值显存不增加**。

## 7. 优点

- **理论视角新颖**：从"下游如何使用特征"出发重述提升操作，把 ℓ2 归一化从"后处理技巧"提升为"目标函数的闭式解"，逻辑自洽且契合 CLIP 余弦几何。
- **一举两得**：同一目标同时给出最优方向（单位向量）与可靠性度量（范数），避免了"提升 + 独立后处理"两阶段设计。
- **可靠性信号内生于公式**：不需要外部可见性启发式，且实证上与大范围不透明度信号基本独立，信息互补性强。
- **尊重流形结构**：精炼采用模式投票（复制单一方向）而非线性平均，构造上保持单位球约束，规避了 CLIP 线性混合导致的语义漂移。
- **完全免训练、轻量高效**：无需逐场景语义优化，后处理速度快，显存开销与基线持平，工程落地友好。
- **实验组织规范**：与基线共享提升阶段做公平对比，消融与超参数敏感性分析详实，并额外提供单调性、相关性等诊断性证据。

## 8. 不足与局限

- **依赖固定输入**：框架把 alpha 合成权重与底层 3DGS 几何作为固定输入，重建阶段产生的几何伪影会直接传播到提升结果中。
- **继承 CLIP 固有缺陷**：在细粒度类别、组合概念、训练分布外对象上表现受限。
- **评测覆盖有限**：3D 评测仅限 ScanNet 室内场景，建筑级、室外、动态场景的泛化性尚未验证；2D 评测仅为附录中的补充实验。
- **精炼的邻域假设**：模式投票要求不可靠高斯的空间邻居中至少存在部分可靠者；若某区域整体不可靠，则无法恢复，需要主动视角规划等额外线索。
- **理论定位的边界**：论文自述范数分解是"代数恒等式"而非定理，余弦对齐目标的推导较为直接；此外，3D 侧与渲染侧两种解释之间更严格的联系（例如何时渲染侧重建最优与逐高斯余弦最优一致）未被深入刻画。
- **零证据区域处理**：$f_j=0$ 时最大化问题解不唯一，论文通过 $R(j)=0$ 标记并交由精炼修正，但该退化情形的理论处理相对简化。

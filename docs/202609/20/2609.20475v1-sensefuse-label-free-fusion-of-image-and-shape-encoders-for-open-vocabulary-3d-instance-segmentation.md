## 摘要
开放词汇场景理解是机器人学的基础，为空间推理和物体操作奠定基础。尽管封闭词汇的3D实例分割大量利用3D形状信息，但最先进的开放词汇方法在掩码标注过程中仍主要局限于2D图像特征或图像蒸馏表示。本文提出 SenseFuse，一种无标签融合方法，平衡2D图像与3D形状编码器，以实现稳健的开放词汇3D实例分割，仅对现有流程中的掩码标注阶段进行改进。我们发现，2D图像编码器与3D形状编码器表现出大体上互不重叠的失败模式，且很少共享相同的错误标签，而两个2D图像编码器则经常重复相同的错误。这种截然不同的行为使得2D与3D组合具有内在互补性。我们引入一种自适应机制，选择场景级融合权重，以最大化一种无标签敏感度度量；该度量可在毫秒内直接从单个场景的未标注候选实例中估计得到。SenseFuse 在 ScanNet200、Replica 和 ScanNet++ 的每个评估设置中都提高了标注准确率，恢复了使用 oracle 权重所能获得增益的67–100%（中位数93%），并在报告的22个设置中的21个中提升了实例AP。代码可在 https://github.com/hanes1207/SenseFuse 获取。

## Abstract
Open-vocabulary scene understanding is fundamental for robotics, laying the groundwork for spatial reasoning and object manipulation. While closed-vocabulary 3D instance segmentation heavily leverages 3D shape information, state-of-the-art open-vocabulary methods remain predominantly restricted to 2D image features or image-distilled representations during mask labeling. In this paper, we propose SenseFuse, a label-free fusion method that balances 2D image and 3D shape encoders for robust open-vocabulary 3D instance segmentation, refining only the mask-labeling stage of existing pipelines. We reveal that 2D image and 3D shape encoders exhibit largely disjoint failure patterns and rarely share identical wrong labels, whereas two 2D image encoders frequently repeat the same errors. This distinct behavior makes the 2D and 3D pair inherently complementary. We introduce an adaptive mechanism that selects a scene-level fusion weight to maximize a label-free sensitivity measure, estimated directly from a single scene's unlabeled proposals in milliseconds. SenseFuse improves labeling accuracy in every evaluated setting across ScanNet200, Replica, and ScanNet++, recovering 67-100% (median 93%) of the gain achievable with an oracle weight, and it raises instance AP in 21 of 22 reported settings. Code is available at https://github.com/hanes1207/SenseFuse.

## 1. 核心问题与研究动机

- **背景**：开放词汇场景理解是机器人空间推理与物体操作的基础能力。封闭词汇的 3D 实例分割（3DIS）大量利用 3D 形状与几何信息，但其固定类别集无法泛化到新类，因而催生了开放词汇 3DIS（含基于训练与免训练两类范式）。
- **核心问题**：现有最先进的开放词汇 3DIS 方法（如 Open-YOLO3D、OpenMask3D、Open3DIS）在**掩码标注阶段**几乎完全依赖 2D 图像编码器或图像蒸馏表示，**原生的 3D 形状证据被完全闲置**，导致在遮挡、深度主导的场景中（例如被桌子遮挡的椅子被误判为"桌子"）出现关键失败。
- **关键经验观察**：2D 图像编码器与 3D 形状编码器表现出**大体互不重叠的失败模式**，很少共享相同的错误标签（2D–3D 对共享错误率仅 5.9%，而两个 2D 编码器之间高达 41.4%）。因此 2D–3D 配对比"再引入一个 2D 编码器"更具融合价值。
- **整体含义**：论文提出 SenseFuse，一种**免标签、免训练、即插即用**的融合模块，仅改进现有流程的掩码标注阶段，让机器人进入陌生环境时无需额外监督或重训练即可重新校准实例标签。

## 2. 方法论

### 2.1 核心思想
- 保留现有 3DIS 流程的掩码提议与 2D 图像嵌入，额外引入一个**冻结的 3D 形状编码器**（Uni3D 或 OpenShape），对掩码点云直接打分。
- 用**单个场景级标量权重 w** 线性融合两个打分头，权重的选取不依赖任何真值标签，仅从单场景未标注提议中在毫秒级估计得到。

### 2.2 关键技术细节与公式

- **问题设定**：给定 RGB 点云 P，继承 Q 个二值实例掩码 {Mq} 与 2D 嵌入 z²q，另用冻结 3D 编码器对掩码点云 Pq 生成 z³q（重采样至 N0=10⁴ 点、居中并缩放至单位球）。两个头各自用自己的文本编码器对同一类别名生成锚点 tʰ,c，所有嵌入 ℓ2 归一化。
- **分数中心化（Eq.1）**：由于两个编码器投影到不同文本对齐空间，原始余弦分数不可直接比较，故将每个掩码的 K 个分数减去其均值：Sʰq,c = sʰq,c − (1/K)Σc′ sʰq,c′。
- **敏感度度量（Eq.2）**：借用信号检测理论的判别指数 d′h = μh/σh，其中 μh 为正确类分数相对背景的平均抬升，σh 为背景（错误类）分数的标准差，二者在同一场景内跨类跨掩码近似共享。
- **线性融合（Eq.3）**：Sq,c(w) = (1−w)S²q,c + wS³q,c，最终标签 Ŷq = argmax_c Sq,c(w)。
- **闭式最优权重（Eq.5）**：假设两个头的背景分数不相关，融合后敏感度 d′w = [(1−w)μ2+wμ3] / √[(1−w)²σ²2+w²σ²3]，令 ∂d′w/∂w=0 得
  **w_law = (μ3/σ²3) / (μ2/σ²2 + μ3/σ²3)**，记 πh = μh/σ²h 则为 w = π3/(π2+π3)，自然落在 [0,1] 内。在分数为高斯、共享对角协方差的假设下，该式等价于 LDA 且为均匀先验下的贝叶斯最优。
- **免标签估计（Alg.1）**：由于 μh 需真值标签，用软责任替代硬伪标签并迭代：
  - 软类责任 Pq,c = softmax_c(Sq,c(w)/(τ0νq))，背景分布 Γq,c = (1−Pq,c)/(K−1)；
  - 掩码子集权重 gq ∝ [1+e^(−β·m̃q)]⁻¹（m̃q 为标准化后的 top-1/top-2 间隔），实现连续松弛的难例筛选；
  - 用责任加权的均值/方差更新 (μ̂h, σ̂h)，再由 Eq.5 更新 w，循环至收敛（默认 τ0=0.25, β=8, Rmax=12, ε=10⁻³）。
  - 该软松弛在 τ0→0、β→∞ 时退化为硬 argmax 估计；由于映射连续且 [0,1]→[0,1]，由介值定理保证不动点存在。
- **最终输出**：收敛的场景权重 ŵ 与硬标签；为 mAP 评估，每个掩码的实例置信度固定为 1.0（沿用现有流程约定）。

## 3. 实验设计

- **数据集/基准**：

- **对比基线流程**（均只替换其最终类别分配，掩码与置信度不变）：

- **3D 头**：默认 Uni3D-giant，模态配对研究中另用 OpenShape PointBERT-ViT-g/14。

## 6. 主要结论与发现

- SenseFuse 在**所有 11 个（流程，数据集）设置中均提升标注准确率**，中位 +7.1 点（范围 +3.8 至 +25.1 点）。
- **免标签权重恢复 oracle 增益的中位 93%**（最低 67%）；数据集级 ŵ 与逐场景 ŵi 均值偏差 ≤0.04，二者准确率相当。
- AP 在 **22 个设置中的 21 个提升**，最高 +4.5 mAP；ScanNet200 和 ScanNet++ 的增益经 bootstrap 检验均显著。
- **互补性验证**：2D–3D 对共享错误仅 5.9%、秩相关 ρ∈[0.079,0.226]，远低于 2D–2D 对的 41.4% 与 ρ=0.677；更强的 2D 头（CLIP）单独精度更高，但与 EVA 融合仅 +1.2 点，而较弱的 Uni3D 融合带来 +4.5 点，证明**互补性而非单头强度**是增益来源。
- **类别级规律**：几何区分度高的类别（浴室隔间门 +62 pp、淋浴墙 +30 pp、扶手椅 +29 pp）大幅改善；纹理/上下文定义的小物体（纸巾盒 −22 pp、纸巾分配器 −21 pp）退化，且退化集中在稀疏掩码（最低点数四分位 −2.1 pp，第三四分位 +8.4 pp）；<1000 点的小掩码占 ScanNet200 的 28%、ScanNet++ 的 0.7%，与 ScanNet++ 增益更高一致。
- **融合位置很关键**：在 argmax 之前做分数级融合（线性或 PoE）优于决策级路由/Veto（后者反而损失 1.2–1.6 点）。
- **权重不敏感但非通用**：存在宽泛的准确率平台（距峰值 1 点内跨度 0.06–0.27），ŵ 跨设置从 0.085 到 0.472 变化；单一全局常数权重仅恢复均值 81% 的 oracle 增益，固定 w=0.30 甚至会使 ScanNet++/Open3DIS 低于 2D-only 水平。

## 7. 优点

- **问题切入精准**：抓住开放词汇 3DIS 标注阶段 3D 形状证据缺失这一被忽视的环节，且通过量化失败模式互补性（共享错误率、秩相关、救援率）为融合提供实证依据。
- **理论支撑清晰**：以信号检测理论的 d′ 为可靠性度量，推导出闭式权重，并在高斯假设下与 LDA/贝叶斯最优决策规则一致；明确说明实际部署只依赖经验矩，不强加分布假设。
- **免标签、免训练、即插即用**：不改掩码几何、不重训骨干，仅替换最终类别分配，可无缝接入三类主流流程；软责任 EM 式迭代保证不动点存在并具备初始化鲁棒性。
- **极低开销**：权重估计仅 3.5 ms/场景，可与 2D 标注并行，单卡串行也仅增加 18% 时间。
- **实验客观性强**：统一重跑并重新评测所有基线以消除协议差异；用标注准确率作为主指标剥离提议召回干扰；同时报告两种 AP 提交规则；消融覆盖融合规则、相关性修正、初始化、超参与运行时。

## 8. 不足与局限

- **粒度受限**：每个场景仅拟合**一个全局权重**，无法刻画实例级模态可靠性差异（作者自认，并列为未来工作方向）。
- **性能天花板受弱头约束**：融合增益上限由较弱的 3D 形状编码器决定；OpenShape 相关性最低但因单独精度过低，增益仅 +0.9/+1.6 点。
- **特定类别退化**：纹理/上下文主导的小物体（纸巾盒、纸巾分配器等）准确率下降，且退化集中在点数最低的四分位稀疏掩码。
- **统计显著性不足的场景**：Replica 仅 8 场景，bootstrap 检验下 4 个增益只有 1 个可分辨；部分结论（如 Replica 的 oracle 恢复率 67%）稳健性有限。
- **跨场景权重不通用**：ŵ 跨设置波动较大（0.085–0.472），单一常数权重无法替代逐场景估计，限制了"零成本迁移"的想象空间。
- **方法假设的近似性**：Eq.5 忽略跨模态背景相关（实测 ρ̂∈[0.14,0.26]），虽作者论证显式修正反而降低准确率并可能产生不可行权重，但该近似在相关性更高的场景下是否仍稳健未充分探讨。
- **基线覆盖缺口**：OpenMask3D 无 ScanNet++ 提议，导致该流程仅覆盖两个数据集；Open-YOLO3D 原生稀疏检测计数空间被排除在连续余弦模型之外，仅能以 Dirichlet 先验形式微弱融入。
- **应用限制**：论文面向静态重建室内场景，未验证动态/室外场景或真实机器人闭环任务中的表现。

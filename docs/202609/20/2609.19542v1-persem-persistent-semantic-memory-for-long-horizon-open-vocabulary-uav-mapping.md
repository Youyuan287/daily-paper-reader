## 摘要
开放词汇分割使无人机能够进行丰富的语义感知，但逐帧预测在重复观测和视角变化下仍可能在时间上不一致。我们提出 PerSeM，一个无需训练的持久语义记忆框架，用于长时程开放词汇无人机建图。PerSeM 将逐帧语义观测与持久的世界空间体素关联起来，并构建基于多数的语义记忆，再通过保留历史的空间精化、信任感知回放和上下文引导验证对其进行保守精化。在 Forest 和 UAVScenes 基准上的实验表明，与逐帧预测相比，持久 3D 记忆在语义正确性和时间稳定性方面带来了显著提升。在这一强持久记忆基线之上，PerSeM 还提供了一致的额外改进，在全部五个评估的 UAVScenes 序列上同时提升了语义准确性和时间稳定性。使用独立于最终 PerSeM 预测所识别的区域进行的分析进一步表明，这些增益集中在语义困难且时间不稳定的区域，而这些区域中基于多数的记忆最可能仍然不确定。这些结果表明，持久 3D 聚合为长时程语义建图提供了坚实基础，而对不确定记忆状态的保守精化无需重新训练或额外神经网络推理即可带来额外改进。

## Abstract
Open-vocabulary segmentation enables rich semantic perception for UAVs, but frame-wise predictions can remain temporally inconsistent across repeated observations and changing viewpoints. We present PerSeM, a training-free persistent semantic memory framework for long-horizon open-vocabulary UAV mapping. PerSeM associates frame-wise semantic observations with persistent world-space voxels and constructs a majority-based semantic memory, which is conservatively refined through history-preserving spatial refinement, trust-aware replay, and context-guided verification. Experiments on the Forest and UAVScenes benchmarks show that persistent 3D memory provides substantial gains in semantic correctness and temporal stability over frame-wise predictions. Beyond this strong persistent-memory baseline, PerSeM provides consistent additional improvements, improving both semantic accuracy and temporal stability across all five evaluated UAVScenes sequences. Analysis using regions identified independently of the final PerSeM predictions further shows that these gains are concentrated in semantically difficult and temporally unstable regions, where majority-based memory is most likely to remain uncertain. These results demonstrate that persistent 3D aggregation provides a strong foundation for long-horizon semantic mapping, while conservative refinement of uncertain memory states can provide additional improvements without retraining or additional neural-network inference.

## 1. 核心问题与整体含义

- **研究背景**：开放词汇语义分割（如 SAM、SegEarth-OV）结合大规模视觉-语言基础模型，使无人机（UAV）无需任务特定重训练即可识别多样语义概念，支撑自主导航、主动感知、可通行性推理与避障规划等下游能力。
- **核心问题**：无人机视频流中的逐帧语义预测在**视角变化、稀疏重访、视觉歧义**下存在显著的**时间不一致性**。作者分析发现，语义波动集中在**少量反复出现的场景区域**，逐帧预测无法在世界空间中维持持久语义。
- **现有方法局限**：已有的时间一致性方法（MaskProp、STCN、AOT、XMem、Video K-Net 等）主要在 **2D 图像/视频域**通过时间平滑、特征对应和短期记忆工作，而机器人交互发生在**持久 3D 环境**中，语义需跨多次观测与视角变化累积。
- **关键观察**：持久的**世界空间聚合**（world-space aggregation）已能解决大部分逐帧不稳定性；剩余挑战不是全局聚合，而是**识别并修正不确定的记忆状态而不扰动稳定分配**。
- **整体含义**：论文提出 PerSeM——一个作为持久 3D 记忆之上"保守精化层"的免训练框架，将修正残余不确定记忆状态确立为长时程开放词汇建图的关键挑战。

## 2. 方法论

### 2.1 核心思想
- 将逐帧语义观测**关联到持久的世界空间体素**而非独立处理图像，每个体素维护跨重复视角的观测历史。
- 流程：**多数投票持久体素记忆 → 保历史空间精化 → 信任感知证据回放 → 上下文引导验证**，采用保守设计，仅在时间与空间证据一致时才修正。
- 整个框架**无需训练、无需额外神经网络推理**。

### 2.2 关键技术细节与算法流程

- **① 持久体素记忆（Persistent Voxel Memory）**
  - 利用逐帧语义预测、深度估计和相机位姿，将有效语义观测反投影到世界坐标并体素化。
  - 为防止密集采样区域主导记忆，同一帧内落入同一体素的观测先用**多数投票**聚合成单一观测，置信度取该体素内的语义一致度。
  - 每个体素 v 维护按时间排序的观测历史 `Hv = {(ci, si, ti)}`（标签、置信度、帧索引）。
  - 累积类别证据：`hv(c) = Σ_i si·1[ci=c]`；初始记忆标签 `cM(v) = argmax_c hv(c)`。

- **② 保历史空间精化（History-Preserving Spatial Refinement）**
  - 将累积证据归一化为概率 `pv(c)`，计算空间邻域 N(v) 上的平均历史分布 `qv(c)`。
  - 软组合：`p̃v(c) = (1-η)·pv(c) + η·qv(c)`，η 控制邻域贡献；锚点标签 `cH(v) = argmax_c p̃v(c)`。
  - 与硬性邻域投票不同，此步引入局部支撑但**不丢弃体素自身累积证据**；被此步修改的体素**受保护**，不被后续信任回放覆盖。

- **③ 信任感知证据回放（Trust-Aware Evidence Replay）**
  - 仅对"历史锚点仍保持多数记忆标签"的复现体素，按序回放观测历史。
  - 每条观测的信任权重：`wi = si · exp(-λv·ρ(ci)) · exp(-λs·gi) · exp(-λt·Δti)`，其中 ρ 为类别波动性、gi 为与当前主流信念的分歧、Δti 为与前一观测的时间间隔。
  - 回放时证据指数衰减并更新：`ei = γ·ei-1, ei(ci) += wi`，最终时间提议 `cT(v) = argmax_c e(c)`。
  - **重放边际门控**：仅当提议的 replay 证据超过多数标签证据一个边际 τreplay 时，才进入下一步；否则保留历史锚点。

- **④ 保守上下文验证（Conservative Context Verification）**
  - 对通过门控的候选标签 c，同时评估两类空间证据：
    - 硬上下文支持：`Shard(v,c) = (1/|N(v)|)·Σ_u 1[cM(u)=c]`
    - 历史上下文支持：`Shist(v,c) = (1/|N(v)|)·Σ_u pu(c)`
  - 仅当 `Shard(v,cT) - Shard(v,cM) > τcontext` **且** `Shist(v,cT) - Shist(v,cM) > τcontext` 时，才用 cT(v) 替换 cM(v)；否则保留 cH(v)。

- **⑤ 密集语义重投影（Dense Semantic Reprojection）**
  - 用深度、内参和位姿将最终体素标签重投影回各相机视角生成密集语义图，**仅用于评估、时间稳定性分析和可视化**，不修改持久记忆。

## 3. 实验设计

## 6. 主要结论与发现

- **持久 3D 聚合是主要增益来源**：相比逐帧预测，持久 3D 融合在语义正确性和时间稳定性上带来最大提升（Forest：Raw2D 37.49→Raw3D 24.39 Flicker；UAVScenes：13.73→7.27）。
- **PerSeM 提供一致的额外改进**，是唯一在两个基准宏平均上同时改善 PA、mIoU、Flicker 三项指标的持久记忆变体：
  - **Forest**：PA 83.44→84.02，mIoU 39.66→39.84，Flicker 24.39→23.00。
  - **UAVScenes**：PA 81.21→81.41，mIoU 41.50→41.90，Flicker 7.27→6.90（mIoU 与 Flicker 改进在全部 5 条序列上保持）。
  - 注：Consensus + Recency 在 Forest 上 mIoU 达 40.08，但 PA 更低、Flicker 更高。
- **EMA2D 强抑制闪烁但牺牲语义精度**（Forest mIoU 仅 24.45），说明不能靠激进时间平滑换取稳定性。
- **消融结论**：Trust Only 单独使用使三项指标全部退化（PA 80.31、mIoU 38.36、Flicker 8.27），Context Only 改善三项指标（81.47/41.88/6.41），History Blend Only 有小幅一致增益；说明信任线索必须受上下文约束，不应独立决定持久标签。
- **场景依赖性**：信任回放在 HKisland01 上带来 +0.50 PA、+0.86 mIoU（但 Flicker +0.97），在 HKairport01 上却使 PA/mIoU 下降 0.44/0.28 且 Flicker +0.59，表明它是有条件的残余恢复通路而非普适估计器。
- **增益集中于困难区域**（相对 Raw3D Majority）：全体有效像素 ∆PA +0.20 / ∆mIoU +0.41 / ∆Flicker -0.37；边界区域 +0.38/+0.54/-0.80；困难核心 +0.53/+0.52/-0.92；**

高切换区域同样录得一致的正向增益（∆PA、∆mIoU 为正、∆Flicker 为负，具体数值见原文表 4），说明 PerSeM 的收益并非集中在某类特殊结构上，而是**系统性地落在时间语义最不稳定、最需要修正的区域**，且增益幅度随区域困难程度单调递增（全体 < 边界 < 困难核心）。
- **稳定性—正确性权衡**：稳定性—正确性权衡图显示，PerSeM 位于"高正确性 + 高稳定性"的有效前沿上，EMA2D 位于"高稳定性 + 低正确性"一端，Raw3D Majority 位于"较正确但较闪烁"一端，说明 PerSeM 并非通过牺牲语义精度换取平滑，而是在同一权衡曲线上实现了帕累托式改进。
- **定性观察**：可视化结果表明，PerSeM 主要修正了**跨视角反复观测但仍被错误多数标签占据**的体素（如细长结构、类别边界带、稀疏重访区域），而对稳定的大面积同质区域几乎不做改动，符合其"保守精化层"的设计目标。

## 7. 局限与未来方向

- **信任回放的场景依赖性**：实验明确显示信任回放在 HKairport01 上反而损害 PA/mIoU 并增加 Flicker，说明该模块目前是一个**有条件的残余恢复通路**，其触发条件（边际门控 τreplay）尚未能自适应地区分"真正需要修正的记忆"与"已稳定的正确记忆"。如何依据场景几何复杂度、重访密度或观测波动统计来自适应调节门控强度，是有价值的后续方向。
- **超参数敏感性未在主文充分展开**：η（邻域贡献）、λv/λs/λt（信任衰减）、τreplay/τcontext（门控阈值）等参数的敏感性分析与 EMA 衰减扫描被置于补充材料，主实验仅在单一冻结配置下运行，未报告多次运行或统计显著性检验，因而改进幅度（如 Forest PA +0.58）的稳健性仍有待进一步确认。
- **评估范围**：仅在 Forest 与 UAVScenes 两个基准、共 7 条序列上验证，且依赖逐帧语义真值进行定量评估；对更长时间尺度、更大规模场景、以及分类体系差异更大的开放词汇设定，泛化性尚未验证。
- **依赖上游质量**：PerSeM 建立在逐帧语义预测、深度估计与相机位姿之上，其持久记忆的质量受上游深度噪声、位姿漂移与开放词汇模型本身的误分类影响，论文未系统分析这些误差的传播与放大效应。
- **效率定位**：虽然 PerSeM 特定精化的开销很小（Forest 2.82 s / UAVScenes 39.10 s），但整体流程中密集语义重投影占绝对主导（1748.0 s / 353.2 s），说明其当前"研究实现"更偏向离线或准实时评估，而非机载实时部署；作者也强调这些数字表征的是保守精化的开销而非优化后的部署性能。

## 8. 总体评价与贡献定位

- **问题选择精准**：论文没有把"开放词汇语义分割精度"作为目标，而是识别出一个被广泛忽略但实际影响机器人长时程作业的问题——**世界空间中持久语义记忆的残余不确定性**，并把"识别并修正不确定记忆状态而不扰动稳定分配"确立为独立挑战，问题定义清晰且具有现实意义。
- **方法设计克制而合理**：PerSeM 的核心价值在于其**保守性**——通过"历史锚点保护 + 边际门控 + 双空间上下文验证"三重约束，确保只有在时间与空间证据同时一致时才修改记忆。消融实验证明这种保守设计是必要的：一旦放松（Trust Only），三项指标全部退化。
- **实验说服力较强**：共享观测/几何/体素化的公平对比、覆盖 5 种持久融合基线的横向比较、独立于真值定义的困难区域分析、以及主动报告的负面结果（Trust Only 退化、HKairport01 上的信任回放失效），共同构成了较为可信的证据链，避免了"只报喜"的常见问题。
- **免训练特性实用**：整个框架不引入额外网络与训练成本，可直接叠加在现有开放词汇分割 + 3D 建图流程之上，工程落地门槛低，峰值内存（0.93–3.17 GB）在无人机平台上具备可行性。
- **总结**：PerSeM 的主要贡献不在于提出新的网络结构，而在于**重新框定问题**——长时程开放词汇建图的瓶颈已从"全局聚合"转移到"残余不确定性的保守修正"，并提供了一个免训练、可插拔、在困难区域收益显著的精化层。其局限（场景依赖性、超参数敏感性、上游依赖）也为后续研究留下了明确切入点。

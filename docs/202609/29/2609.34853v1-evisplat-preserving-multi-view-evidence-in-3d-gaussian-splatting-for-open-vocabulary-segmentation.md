## 摘要
开放词汇3D场景理解能够根据自由形式的文本查询进行目标定位和分割，而无需固定的类别词表。许多近期方法建立在3D高斯泼溅之上，并在查询已知之前，将多视角观测（例如来自单个视角的掩码裁剪）整合为语言特征或紧凑的目标描述子。然而，同一目标的观测会随视角变化，且信息量并不相同：有些揭示了与特定查询相关的线索，而另一些则提供不完整或误导性的证据。因此，查询前的整合可能抑制后续查询所依赖的线索。我们提出EviSplat，它保留个体观测特征，作为后续文本查询的证据。EviSplat将个体观测特征保留在类别无关的3D实例中，这些实例表示目标、目标部件或背景区域。它还为每个高斯学习一个分布，描述其观测支持哪些视觉外观。给定文本查询，EviSplat使用每个实例最相关的观测来对其评分。然后，它通过将实例级相关性与局部支持的证据相结合，为每个高斯计算得分，并根据该高斯被观测到的频率和明确程度进行加权。因此，不同查询可以从同一保留证据中利用不同的视觉线索。在不同数据集和评估协议上的实验展示了最先进的性能，支持了将多视角证据保留至查询时并依据查询进行聚合的优势。

## Abstract
Open-vocabulary 3D scene understanding enables object localization and segmentation from free-form text queries without a fixed category vocabulary. Many recent methods build on 3D Gaussian Splatting and consolidate multi-view observations, such as masked crops from individual views, into language features or compact object descriptors before the query is known. However, observations of the same object vary across viewpoints and are not equally informative: some reveal cues relevant to a particular query, whereas others provide incomplete or misleading evidence. Pre-query consolidation can therefore suppress cues on which a later query depends. We introduce EviSplat, which preserves individual observation features as evidence for later text queries. EviSplat retains individual observation features within class-agnostic 3D instances that represent objects, object parts, or background regions. It also learns, for each Gaussian, a distribution describing which visual appearances its observations support. Given a text query, EviSplat scores each instance using its most relevant observations. It then computes a score for each Gaussian by combining instance-level relevance with locally supported evidence, weighted by how often and how unambiguously that Gaussian was observed. Different queries can thus draw on different visual cues from the same preserved evidence. Experiments across diverse datasets and evaluation protocols demonstrate state-of-the-art performance, supporting the benefit of preserving multi-view evidence until query time and aggregating it according to the query.

## 1. 核心问题与研究动机

- **任务背景**：开放词汇 3D 场景理解旨在用自由形式的文本查询（而非固定类别词表）在重建的三维场景中定位与分割目标。当前主流方案以 3D Gaussian Splatting（3DGS）为场景表示，将语言线索存储为逐高斯的语言特征，或附着在类别无关的 3D 实例（目标／部件／背景区域）上的描述子。
- **核心痛点**：现有方法普遍采用**查询前整合（pre-query consolidation）**——在文本查询尚未给出时，就通过特征蒸馏或描述子聚类把多视角观测（各视角的 SAM 掩码裁剪经 CLIP 编码得到的特征）合并为单一特征或紧凑描述子。
- **问题本质**：同一目标在不同视角下的观测信息量并不等价：有的视角揭示与特定查询相关的线索，有的则因遮挡、模糊或掩码不准而不完整甚至误导。一旦提前整合，后续查询就**无法在原始观测之间进行选择**，可能压制查询所依赖的关键线索（论文 Fig. 1 用 IoU 0.46 vs 0.91 直观展示）。
- **整体含义**：论文主张把多视角证据**保留到查询时刻**，再依据查询动态聚合，从而让不同查询从同一份证据中抽取不同的视觉线索，且无需重新训练表示。

## 2. 方法论

### 2.1 核心思想

EviSplat 用**两级证据表示**替代传统的"聚合特征 + 相关性打分"：
- **实例观测库（instance observation banks）**：保留实例级的多视角个体观测特征，供查询时选择；
- **高斯证据场（Gaussian evidence field）**：为每个高斯学习一个外观分布，记录该高斯局部被哪些外观支持。

查询到来时，先用实例最相关的观测形成**实例先验**，再用**可靠性加权的高斯局部证据**对其修正。

### 2.2 阶段一：多视角证据保留（无文本、无标签）

- **观测与实例分组**：每个观测 $o$ 由源视角、SAM 掩码 $m_o$ 及其裁剪的 unit-norm CLIP 特征 $x_o$ 组成。沿用 LaGa 的类别无关亲和场 $a_g$，对掩码区域池化得到观测级亲和特征 $a_o$，再用 HDBSCAN 跨视角聚类，得到 3D 实例 $i\in I$ 及其观测库 $B_i\subseteq O$。实例依语义尺度可对应目标、部件或背景。
- **证据集 $E_g$**：为刻画"某观测在实例内被支持于何处"，对每个高斯 $g$ 与每个源视角 $v$，定义关联度 $u_g(o)$ 为高斯渲染质量落在掩码 $m_o$ 内的比例（用式 (1) 的 α 合成权重计算，天然考虑遮挡与透射）。每视角取关联度最大的观测 $o_g^{(v)}$，保留正关联者构成证据集 $E_g$。
- **观测权重**：以相对次优者的边际定义置信度 $\omega_g(o)=1-\max_{o'\neq o}u_g(o')/u_g(o)\in[0,1]$，再按视角归一化，使每个视角总权重为 1，避免关联高斯多的视角获得过高权重。
- **证据分布与学习**：单一均值特征无法唯一确定观测分布，且因相关性函数非线性，$r(\bar x_g,t)\neq \mathbb{E}[r(x,t)]$。因此用 spherical K-means 构建**冻结的视觉原型码本** $C=\{c_k\}_{k=1}^K$，把每个高斯的证据集表示为其最近原型的加权直方图 $q_g(k)$。为控制存储，为每个高斯学习共享隐向量 $z_g\in\mathbb{R}^D$ 与每尺度线性解码器 $W$，以 $p_g=\mathrm{softmax}(Wz_g/\|z_g\|_2)$ 逼近 $q_g$，损失为交叉熵 $L_{evid}$，高斯按总权重采样。
- **可训练参数仅为隐向量与解码器**；3DGS 场景、CLIP 编码器、亲和场全部冻结，训练不使用文本查询或类别词表。

### 2.3 阶段二：查询引导的证据聚合

最终高斯得分：$s_g(t)=b_g(t)+\rho_g\max(e_g(t)-b_g(t),0)$，三项分别为：

- **实例先验 $b_g(t)$**：对观测库中每个观测的 LERF 相关性 $r(x_o,t)$ 取 **top-β 均值**（β=1 为平均池化，β→0 为最大池化），得实例相关性 $R_i(t)$；再经查询无关的软亲和分配 $\pi_g(i)\propto\exp(\cos(a_g,a_i)/T)$ 加权传递到高斯。注意：只有观测得分随查询变化，CLIP 特征始终分开保留。
- **高斯局部证据 $e_g(t)$**：对码本原型计算相关性 $r(c_k,t)$，在**固定概率质量 γ** 约束下最大化平均相关性——$\max_\delta \frac{1}{\gamma}\sum_k\delta(k)r(c_k,t)$，s.t. $0\le\delta(k)\le p_g(k)$，$\sum_k\delta(k)=\gamma$。按相关性降序贪心填充，高相关但低概率的原型只按其质量贡献。γ=1 退化为期望相关性。
- **观测可靠性 $\rho_g$**：由证据集规模与关联确定性给出 $\rho_g=\frac{n_g}{n_g+\bar n}\bar\omega_g$，其中 $\bar n$ 为场景内平均观测数（不引入额外超参），$\bar\omega_g$ 为平均分配边际。局部证据不足或不明确时，修正幅度自动减小。
- **多尺度与分割**：在各语义尺度上求得的 $s_g^{(\ell)}(t)$ 取平均，阈值化后渲染选中高斯得到掩码。新查询只改变 $r(x_o,t)$ 与 $r(c_k,t)$，表示、$\pi_g$、$\rho_g$ 均一次构建、多查询共享。

## 摘要
最近的3D视觉语言模型(3D VLMs)通过将2D视觉特征投影到世界坐标来构造几何感知的token，从而为3D问答等任务实现空间推理。然而，这种设计每个场景生成数千个token，导致大量的计算和内存开销。虽然token压缩在2D VLMs中已被广泛研究，但现有方法依赖于语义相关性或基于注意力的选择，忽略了3D token的结构化空间特性。此外，3D表示中的冗余不能仅通过空间邻近性解决，因为在空间聚合后，对象级token不平衡仍然存在。为了解决这个问题，我们提出了3DZip，一个三阶段的token压缩框架：首先应用粗体素化去除点级冗余，然后通过行列式点过程基于特征空间多样性选择锚定token，最后在空间约束下合并剩余token以保持几何一致性。在三个3D问答基准上的实验表明，3DZip持续优于现有的压缩方法，仅用128个token就保留了原始性能的94.7%，实现了1.92倍的推理速度提升。

## Abstract
Recent 3D vision-language models (3D VLMs) construct geometry aware tokens by projecting 2D visual features into world coordinates, enabling spatial reasoning for tasks such as 3D question answering. However, this design generates thousands of tokens per scene, resulting in substantial computational and memory overhead. While token compression has been extensively studied in 2D VLMs, existing approaches rely on semantic relevance or attention-based selection that overlook the structured spatial nature of 3D tokens. Moreover, redundancy in 3D representations cannot be resolved by spatial proximity alone, as object-level token imbalance persists even after spatial aggregation. To address this, we propose 3DZip, a three-stage token compression framework that first applies coarse voxelization to remove point-level redundancy, then selects anchor tokens based on feature-space diversity via a Determinantal Point Process, and finally merges remaining tokens under spatial constraints to preserve geometric coherence. Experiments on three 3D question answering benchmarks demonstrate that 3DZip consistently outperforms existing compression methods, retaining 94.7% of the original performance with only 128 tokens, achieving a $1.92\times$ faster inference speed.

## 2. 论文提出的方法论

### 2.1 核心思想

论文将3D多视图表示中的冗余分解为三个互补层次：**点级冗余**（多视角同一表面对应多个重叠token）、**对象级冗余**（同一物体的多个表面区域被分别token化）、以及**几何一致性**（token合并时需保持空间结构）。3DZip据此设计为三阶段压缩流程：

### 2.2 三阶段算法流程

- **阶段1：粗体素化**——将3D空间划分为给定尺寸（δ=0.2m）的轴对齐体素，对同一体素内的token做均值池化，减少多视图投影造成的点级重叠冗余，得到体素化token集Vvox。
- **阶段2：特征多样性引导的锚点选择**——对体素化后的token特征做L2归一化，构造余弦相似度核矩阵L，采用**行列式点过程（DPP）**的贪心近似（基于Cholesky分解）选取K个特征上最多样化的锚点token。该步骤优于基于空间坐标的DPP（XYZ-DPP），能够更均匀覆盖场景中不同物体实例。
- **阶段3：空间约束的token合并**——对每个非锚token，在特征空间中找最近锚点，仅当网格空间距离 dg(j,a)≤τg（τg=5）时才允许合并到该锚点；不满足约束的孤立token被丢弃。锚点特征更新为自身与所分配token的均值，保留锚点原始坐标以保证空间一致性。

### 2.3 关键动机

论文通过实证分析发现：即便经过体素聚合，token在物体间的分配仍呈长尾分布；空间DPP仅覆盖51%的GT物体，而特征DPP可提升覆盖率至70%——这为"特征多样性是3D压缩的关键维度"提供了直接证据。

## 8. 不足与局限

- **小物体与细节信息损失**：粗体素化可能将小物体的token与邻近物体或背景合并，导致小物体和细粒度细节类问题的性能明显下降（Small obj. EM: 19.5 vs 去除体素化的21.6）；

- **评估范围限制**：OpenEQA的HM3D子集缺失；3D密集描述仅一个数据集（Scan2Cap）；缺乏真实机器人/具身环境部署验证；
- **训练目标兼容性**：方法为推理期、训练无关设计，未验证与微调训练的联合优化；DPP选择耗时虽低于DTC但仍占推理延迟约10%，存在进一步优化空间；
- **潜在偏差风险**：DPP锚点选择偏向特征突出的物体（如颜色鲜明、纹理丰富），在某些场景下可能系统性遗漏外观平淡但语义重要的物体。

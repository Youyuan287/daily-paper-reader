## 摘要
视觉语言模型（VLM）日益被部署为现实世界视觉评估流程中的推理代理，然而其空间接地能力对于细粒度、视觉模糊的目标仍然不可靠。我们在自动车辆损伤评估的背景下研究这一差距，其中诸如划痕和发丝裂纹等细粒度缺陷仅占据少量像素，产生微弱的梯度信号，且容易与反射和表面纹理混淆。我们表明，最先进的VLM（Qwen-VL）在此任务上实现了强大的语义分类准确率（87.3%），但在空间层面系统性地缺乏接地能力：它在反射区域产生损伤幻觉，完全遗漏细长划痕，并在提示定位时产生空间不一致的输出。我们提出TinyDamage，一种混合架构，将空间接地委托给专用的多任务分割模型，同时保留VLM用于语义推理和报告生成。在分割方面，我们发现损失函数的选择对微小目标接地具有巨大且未被充分探索的影响：广泛用于类别不平衡的焦点损失会将微小损伤检测崩溃至零，而有监督的对比目标则显著改善损伤/背景的可分离性。我们将分割模型集成到一个7节点LangGraph代理流程中，该流程将VLM的每个生成步骤都接地在分割输出上，并表明在100份人工验证报告的控制评估中，这种接地将报告幻觉率从92%（仅文本）和78%（仅图像）降低至31%。我们引入了DET_l，一种用于在类别不平衡下评估微小目标接地的每类别宽容检测指标，并报告了部署流程的延迟和可靠性特征。

## Abstract
Vision-language models (VLMs) are increasingly deployed as reasoning agents in real-world visual assessment pipelines, yet their spatial grounding remains unreliable for fine-grained, visually ambiguous targets. We study this gap in the context of automated vehicle damage assessment, where fine-grained defects such as scratches and hairline cracks occupy few pixels, produce weak gradient signal, and are easily confused with reflections and surface texture. We show that a state-of-the-art VLM (Qwen-VL) achieves strong semantic classification accuracy (87.3%) on this task but is systematically ungrounded at the spatial level: it hallucinates damage in reflective regions, misses elongated scratches entirely, and produces spatially inconsistent outputs when prompted for localization. We propose TinyDamage, a hybrid architecture that delegates spatial grounding to a dedicated multi-task segmentation model while reserving the VLM for semantic reasoning and report generation. On the segmentation side, we find that the choice of loss function has an outsized and underexplored effect on tiny-object grounding: focal loss, widely used for class imbalance, collapses tiny-damage detection to zero, while a supervised contrastive objective measurably improves damage/background separability. We integrate the segmentation model into a 7-node LangGraph agent pipeline that grounds every VLM generation step in the segmentation output, and show that this grounding reduces the report hallucination rate from 92% (text-only) and 78% (image-only) to 31% in a controlled evaluation on 100 human-verified reports. We introduce DET_l, a permissive per-category detection metric for evaluating tiny-object grounding under class imbalance, and report latency and reliability characteristics of the deployed pipeline.

- **研究场景**：自动车辆损伤评估（保险理赔场景）。细粒度损伤如划痕、发丝裂纹仅占图像数个像素，梯度信号微弱，且极易与反射、表面纹理等良性特征混淆，是检验 VLM 空间接地能力的天然压力测试。
- **核心矛盾**：论文通过实验证明，Qwen-VL 在损伤语义分类上准确率高达 87.3%，但空间定位却系统性失败——在反光区域产生损伤幻觉、完全遗漏细长划痕、对近似图片给出不一致的定位结果。这表明问题在于**“概念知道但无法锚定到像素”**，属于接地失败而非纯粹的感知能力不足。
- **整体思路**：与其试图通过提示词或微调“修复”VLM 的定位能力，不如采用**混合架构**——让专用分割模型负责空间接地，让 VLM 负责语义推理和语言生成，并将分割输出作为 VLM 生成的显式条件输入，从根本上消除无依据的生成。

## 2. 论文提出的方法论

- **总体架构**：提出 TinyDamage 混合系统，分为三大模块：
  - **A. 分割模型（TinyDamage）**：负责空间接地，输出损伤掩码、类别预测与像素嵌入；
  - **B. LangGraph 代理流水线**：7 节点状态化编排，将分割输出注入 VLM 的每一步生成；
  - **C. 基础设施层**：可替换 VLM 供应商（本地 Qwen-VL、Gemini、OpenAI）、LangFuse 可观测性、Streamlit 应用接口。

- **TinyDamage 分割模型**（在任意分割骨干上增强三个组件）：
  1. **FPN 多尺度特征提取**：由于微小损伤往往仅在高分辨率特征层可见，FPN 提供了从 P2 到 P5 的多尺度表征，是**增益最大的单一架构改进**（+2.3% 测试 mIoU）；
  2. **微小目标对比模块（Tiny-Object Contrastive Module）**：将解码器特征经轻量 MLP 投影到低维嵌入空间，训练像素级监督对比损失。
     - 对比损失公式：**Lcon = −1/|A| Σₐ log [ exp(zₐ·zₚ/τ) / Σₙ exp(zₐ·zₙ/τ) ]**
     - 负样本采样策略：50% 从损伤边界 δ 邻域内的背景（难负样本），50% 从远处背景均匀采样，迫使模型区分损伤与相邻纹理；
  3. **梯度感知边界模块（Gradient-Aware Boundary Module）**：对预测掩码与真实掩码计算 Sobel 梯度，施加加权 L1 惩罚。权重在损伤边界邻域内放大（β=5.0, δ=3px），**仅作为小权重辅助损失使用**。
  - **总损失**：L = CE + 4·Dice + Focal + 0.1·Lcon + 0.05·Lgrad + Lcls，使用 AdamW + 余弦退火。
  - **辅助分类头**：共享编码器的 6 类损伤分类头（约 50K 参数），提供类别信息但推论时零额外开销。

- **关键发现**：**损失函数选择对微小目标接地的影响被严重低估**。焦点损失（focal loss）作为类别不平衡的默认工具，反而将微小损伤检测崩溃至零——因为其梯度集中于最不确定像素，而这些像素恰好是损伤边界附近的模糊纹理；模型学会抑制不确定区域的预测，连同损伤本身一起抑制。相比之下，**CE+Dice+余弦退火**是最强的简单基线，监督对比学习进一步改善了损伤/背景的可分性。

- **LangGraph 7 节点流水线**：
  1. Segmentation（TinyDamage 推理）→ 2. Damage Analysis（确定性：面积、严重度、成本）→ 3. Policy Resolution（确定性：保单查询）→ 4. Claim Letter（VLM，图像+分割叠加+损伤摘要）→ 5. Damage Report（VLM，多模态）→ 6. Coverage Assessment（VLM，仅文本+Chain-of-Thought）→ 7. Action Plan（VLM，仅文本）。
  - 选择 LangGraph 而非简单链式调用，是为了支持状态化多步推理与节点级重试。

- **新评估指标 DET_l**：由于 mIoU 被大面积类别主导，论文提出逐类别检测指标——对每个真实微小损伤实例，若与任一预测的 IoU 超过阈值 t（默认 0.1）即判定检出，用于衡量“是否找到”而非“重叠多精确”。

## 6. 论文的主要结论与发现

1. **VLM 语义强、空间弱**：Qwen-VL 在损伤语义分类上达 87.3% 准确率，但空间定位系统性失败——反射区幻觉、细长划痕漏检、近重复图不一致；这不是可提示词修复的问题。
2. **混合架构是必要而非可选**：专用分割模型负责空间接地（244.6 ms，近实时），VLM 负责语义推理（分类、生成），两者互补不可替代。
3. **分割接地大幅降低幻觉**：报告幻觉率从 92%（仅文本）和 78%（仅图像）降至 **31%**（图像+分割接地）；残余幻觉表明接地缓解但未根除。
4. **优化选择主导架构选择**：在微小目标接地问题上，从焦点损失切换到 CE+Dice 将 DET_l 从 0.000 提升到 0.667——影响大于任何架构改动。
5. **焦点损失对微小模糊目标有害**：其梯度集中于不确定像素，而微小损伤的边界/纹理恰是模型最不确定的区域，导致模型主动抑制损伤预测；增大 γ 使情况恶化。
6. **DET_l 指标有效性**：从宽松到严格阈值退化平滑（t=0.05 时 0.35 → t=0.5 时 0.04），印证模型“找得到区域但重叠不精确”，宽松检测阈值比严格 mIoU 更能反映微小目标检测能力。

## 7. 优点

- **问题定义清晰**：将 VLM 在细粒度场景下的失败明确区分为“语义能力”与“空间接地”两个维度，并用受控实验定量刻画缺口；
- **混合架构设计合理**：不试图用提示词“绕开”VLM 的空间弱点，而是让专用模型做擅长之事，工程上务实且可部署；
- **意外的损失函数发现**：证明焦点损失在微小模糊目标上会崩溃到零，这一结论具有超越车辆损伤的普适意义（医学影像、工业检测、遥感等）；
- **接地评估设计严谨**：幻觉判定以人工验证掩码为客观标准，而非生成文本内部一致性；在 9B 模型上进行评估以避免生成质量不足带来的混淆；
- **全链路工程落地**：7 节点 LangGraph 流水线 + LangFuse 可观测性 + 延迟/可靠性/失败模式分析，超越了纯算法论文的交付深度；
- **对负面结果诚实报道**：附录列出所有失败方向（梯度损失、焦点损失、VLM 定位等），透明度高。

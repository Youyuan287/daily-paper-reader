## 摘要
基于多视图图像的三维视觉定位预测一个坐标框架以定义坐标系，然后回归一个三维边界框进行定位。然而，现有方法联合优化坐标框架选择和框回归，导致坐标相关的框模糊和定位性能下降。这种模糊性源于同一框在不同坐标框架下具有不同的数值表示，从而产生多个优化目标，并导致无效的折中预测。为了应对这一挑战，我们提出了CoordRefer，一种将坐标框架选择与坐标条件定位解耦的坐标感知框架。CoordRefer首先选择参考框架以定义坐标系，然后基于该坐标系进行三维框预测。我们进行坐标感知的监督微调，以建立坐标框架选择和坐标条件框回归，然后使用基于三维IoU奖励的组相对策略优化，使两个阶段与下游定位质量对齐。在基于Qwen3-VL-2B的ScanRefer上，CoordRefer相比坐标无关基线在Acc@0.25上提升了11%，在Acc@0.5上提升了7%，而其几何精化变体超越了使用显式三维输入的方法。

## Abstract
Multiview image-based 3D visual grounding predicts a coordinate frame to define a coordinate system and then regresses a 3D bounding box for localization. However, existing methods jointly optimize coordinate frame selection and box regression, leading to coordinate-relative box ambiguity and degraded grounding performance. This ambiguity arises because the same box admits different numerical representations across coordinate frames, creating multiple optimization targets and yielding invalid compromise predictions. To tackle this challenge, we propose CoordRefer, a coordinate-aware framework that decouples coordinate frame selection from coordinate-conditioned grounding. CoordRefer first selects a reference frame to define the coordinate system and then conditions 3D box prediction on the coordinate system. We perform coordinate-aware supervised fine-tuning to establish coordinate frame selection and coordinate-conditioned box regression, followed by Group Relative Policy Optimization with 3D IoU-based rewards to align both stages with downstream grounding quality. On ScanRefer with Qwen3-VL-2B, CoordRefer achieves gains of 11% in Acc@0.25 and 7% in Acc@0.5 over the coordinate-agnostic baseline, while its geometrically refined variant surpasses methods using explicit 3D inputs.

# CoordRefer: 基于多视图图像的坐标感知三维视觉定位——论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **任务定义**：基于多视图图像的三维视觉定位（3D Visual Grounding），指模型在给定一段视频的 RGB 图像序列和一条自然语言描述时，需要先在输入帧中选取一个参考坐标系（coordinate frame），再在该坐标系中回归目标物体的 3D 边界框。
- **现有方法的缺陷**：已有工作（如 VG-LLM、3D-RFT、SPAR）大多采用 **坐标无关（coordinate-agnostic）** 的联合优化框架，即同时预测坐标框架索引和对应的 3D 框。这种耦合设计存在一个根本性弱点——**坐标相关框歧义（coordinate-relative box ambiguity）**。
- **歧义的成因**：同一个物理 3D 框在不同坐标系下具有不同的数值表示。联合优化时，模型面对多个等价但不一致的优化目标，可能收敛到一个折中的、**在任何坐标系下都不对应有效 3D 框**的预测结果，导致定位性能下降。
- **核心解决思路**：将坐标框架选择与框回归**解耦**——先选定参考坐标系，再在"坐标条件"下回归 3D 框，使每个训练样本只对应唯一的优化目标，从而消除歧义。
- **本文定位**：基于上述发现，作者提出 **CoordRefer**，一个坐标感知的 RGB-only 3D 视觉定位框架，并用坐标感知监督微调（SFT）+ 组相对策略优化（GRPO）的两阶段训练策略加以实现。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架
- CoordRefer 采用两阶段解耦流程，如下所示（文字版）：
  1. 输入图像集 I 和文本查询 q；
  2. 坐标选择器 F_sel 从 I 中选择一个参考帧 f，用于定义坐标系；
  3. 坐标条件定位器 F_grd 基于 I_grd 和已确定的坐标系 f，预测 9-DoF 3D 框 B_f。
- 与坐标无关框架的区别：坐标无关框架为 `(f, B_f) = F_sel_grd(I, q)`（联合一步预测）；CoordRefer 分解为 `f = F_sel(I, q)` 和 `B_f = F_grd(I_grd, q | f)`（两步骤、显式坐标条件化）。

### 2.2 坐标感知监督微调（Coordinate-Aware SFT）
- **指令构建**：构建两类训练指令——坐标框架选择指令（输出帧索引）与坐标条件定位指令（输出在该坐标系下的 3D 框）。
- **伪坐标框架标签生成**：先通过物体可见性硬约束过滤候选帧，再在可见候选帧中基于**投影尺度（projected scale）**与**几何完整性（geometric completeness）**的平衡选择最优参考帧，并设置了阈值 τ（经验值为 0.6）。
- **时间重采样（Temporal Resampling）**：选定参考帧后将参考帧置首，并补充其时间邻近帧（共 18 帧）作为定位输入 I_grd，增强视觉几何信息。
- **次优帧监督（Suboptimal-Frame Supervision）**：额外使用次优但有效的坐标帧作为替代参考构建训练样本，增强模型对非理想帧选择的鲁棒性。

### 2.3 坐标感知强化学习（Coordinate-Aware RL）
- **算法**：使用 Group Relative Policy Optimization（GRPO），相比 PPO 无需价值网络，通过组内相对比较估计优势函数。
- **三类奖励**：
  - **格式奖励（Format Reward）**：输出必须可解析（有效帧索引或完整 9-DoF 框），否则为 0。
  - **直接 IoU 奖励（用于定位）**：给定参考帧 f，直接以预测框与真实框的 3D IoU 作为奖励。
  - **间接 IoU 奖励（用于坐标选择）**：给定选中的帧 f，用一个冻结的坐标条件定位模型在该帧条件下预测 3D 框，用其 IoU 来衡量该帧对下游定位的实际效用。
- **奖励模型定期刷新**：定位奖励模型每 K=100 步用最新策略权重更新一次，以保持与正在优化的策略一致。
- **联合优化**：在同一 batch 中混合采样两类指令，通过直接与间接 IoU 奖励将坐标选择与定位统一对齐到 3D 定位质量上。

### 2.4 多目标扩展
- 多目标场景下，模型需预测一个**去重的参考帧集合**，每个参考帧下可预测多个框，最后经相机外参变换到全局坐标系后**聚合**，用 F1 分数作为奖励，同时优化实例覆盖率并抑制重复预测。

## 6. 主要结论与发现

1. **解耦有效**：将坐标框架选择与坐标条件定位解耦，相比坐标无关联合优化，在 ScanRefer 上 Acc@0.25 提升 11.4%、Acc@0.5 提升 7.2%。
2. **一致性领先**：RGB-only 模型在所有四个室内基准（ScanRefer/NR3D/SR3D/Multi3DRefer）上均超过现有 RGB-only 方法；在 Multi3DRefer 上 F1@0.25 和 F1@0.5 较基线提升 11.0% 和 6.0%。
3. **可挑战显式 3D 方法**：加入几何精化后，在 ScanRefer 上达到 60.0% Acc@0.25、53.4% Acc@0.5，超越使用点云等显式 3D 输入的 Video-3D LLM 等此前最优方法。
4. **零样本泛化占优**：在 ARKitSceneRefer 跨数据集测试中（7.9% Acc@0.25、0.7% Acc@0.5），显著优于显式 3D 方法（Video-3D LLM 仅 0.2%/0.0%），说明基于 RGB 的方法对域间差异更鲁棒。
5. **两种奖励互补**：直接 IoU 奖励对定位任务提升明显；间接 IoU 奖励（基于下游定位质量评估帧选择）优于简单伪标签一致奖励。
6. **上界尚存空间**：Oracle 帧 + 框精化可将 Acc@0.25 推高至 85.1%、Acc@0.5 至 76.5%，说明坐标帧选择仍是主要瓶颈，精确框回归也仍是优化重点。
7. **共享策略可行**：单 2B 共享策略与双 2B 任务特定策略性能相当，但部署开销大幅降低。

## 7. 优点

- **问题洞察深刻**：明确指出坐标相关框歧义这一结构性缺陷，通过公式对比（坐标无关 vs 坐标条件化）清晰论证歧义产生机制，并有可视化实验（图 2、图 4）佐证。
- **方法设计简洁有效**：不引入额外几何编码器，纯基于 Qwen3-VL-2B 的简单架构即可大幅超越基线，提升可归因于坐标感知公式本身，而非模型规模或额外模块。
- **RL 奖励设计有创意**：用"冻结定位模型在选中帧上的 IoU"作为帧选择的间接奖励，将不可直接量化的"坐标选择质量"转化为可优化的下游定位质量指标；且周期刷新奖励模型以保持与策略一致性。
- **实验分析深入**：上界分析分离了"帧选择误差"与"框回归误差"的贡献；共享 vs 任务特定策略的对比排除了策略干扰疑虑；RL 动态（奖励上升、熵稳定）佐证训练稳定性。
- **代码/可复现信息充分**：补充材料提供了完整提示模板、伪标签构造细节、超参数设置、训练时间与算力配置。
- **附带能力未受损**：验证了 3D 检测和 3D 描述生成能力与基线持平或提升，说明新框架没有牺牲多任务能力。

## 8. 不足与局限

- **坐标帧选择仍是瓶颈**：预测帧与 Oracle 帧之间的性能差距巨大（51.1%→83.2% Acc@0.25），说明模型经常选到目标可见性不足或空间配置不佳的帧，限制了下游定位表现。
- **精确框回归仍有挑战**：Box Refinement 带来了大幅提升（尤其在 Acc@0.5 下 23.6%→53.4%），说明裸模型的粗定位尚可但精细几何估计精度不足。
- **依赖真值相机位姿**：主实验使用 GT 相机位姿进行坐标系变换；用 π3 估计位姿替换后性能下降约 1.8%（Acc@0.25）和 2.9%（Acc@0.5），对位姿精度仍有一定敏感度。
- **零样本跨域性能绝对值低**：ARKitSceneRefer 上仅有 7.9%（Acc@0.25），虽然相对最优但绝对性能仍难满足实际应用需求，跨域泛化仍是开放问题。
- **训练资源消耗大**：RL 阶段需要 64 块 NPU 训练 111 小时，虽然低于某些 R1 式方法，但对普通研究团队仍有较高复现门槛。
- **应用限制**：单目标设定一次只选一个参考帧，若目标在所选帧中遮挡严重或视角极差，即使有次优帧监督和 RL 优化也不能完全弥补；多目标场景的帧数上界由模型自定，可能存在未收敛的不确定性。

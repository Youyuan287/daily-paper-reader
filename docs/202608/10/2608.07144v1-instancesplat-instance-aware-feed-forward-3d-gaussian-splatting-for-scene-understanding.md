## 摘要
前馈 3D 高斯泼溅 (3DGS) 实现了高效且可泛化的 3D 重建，但当前用于场景理解的前馈 3DGS 方法仍主要面向类别。相比之下，实例感知的 3DGS 方法通常依赖于逐场景优化，并且常常将重建与实例和语义学习解耦，限制了它们之间的相互交互。我们提出了 InstanceSplat，一个统一的前馈 3DGS 框架，用于从无姿态多视角图像中进行可泛化的 3D 重建和实例感知的场景理解。在单次前向传播中，InstanceSplat 构建了一个实例感知的高斯表示，联合编码外观、几何、实例身份和语言对齐的语义。共享的 3D 高斯体在视图之间锚定实例身份，产生可渲染且跨视图一致的实例特征。为了让重建和场景理解相互受益，我们进一步设计了一种以实例为中心的学习策略，通过共享的实例结构将重建、实例学习和语义学习连接起来。具体来说，实例线索引导重建，语言对齐的语义增强了对混淆的同类别实例的判别，实例区域将语义证据聚合为连贯的对象级预测。在不同输入视图设置和未见数据集上的新视图合成、实例分割和开放词汇语义理解实验表明了最先进的性能、实用效率和强泛化能力。

## Abstract
Feed-forward 3D Gaussian Splatting (3DGS) enables efficient and generalizable 3D reconstruction, but current feed-forward 3DGS methods for scene understanding remain largely category-oriented. In contrast, instance-aware 3DGS methods typically rely on per-scene optimization and often decouple reconstruction from instance and semantic learning, limiting reciprocal interactions among them. We present InstanceSplat, a unified feed-forward 3DGS framework for generalizable 3D reconstruction and instance-aware scene understanding from pose-free multi-view images. In a single forward pass, InstanceSplat constructs an instance-aware Gaussian representation that jointly encodes appearance, geometry, instance identity, and language-aligned semantics. Shared 3D Gaussians ground instance identities across views, producing renderable and cross-view-consistent instance features. To allow reconstruction and scene understanding to benefit from each other, we further design an instance-centric learning strategy that connects reconstruction, instance learning, and semantic learning through shared instance structure. Specifically, instance cues guide reconstruction, language-aligned semantics strengthen the discrimination of confusing same-category instances, and instance regions aggregate semantic evidence into coherent object-level predictions. Experiments on novel-view synthesis, instance segmentation, and open-vocabulary semantic understanding under varying input-view settings and on an unseen dataset demonstrate state-of-the-art performance, practical efficiency, and strong generalization.

## 一、核心问题与研究动机

- **背景**：3D 高斯泼溅（3DGS）凭借高保真的新视图合成（NVS）和高效渲染，已成为 3D 场景表示的主流选择。但标准 3DGS 仅用于视觉重建，**不显式编码实例结构或语义信息**，难以直接支撑机器人导航、物理交互等下游任务。
- **现有方法的不足**：
  - **场景特定优化类方法**（如 Gaussian Grouping、OpenGaussian、InstanceGaussian）：虽然能做实例分割和语义查询，但需要逐场景优化，且通常将重建、实例学习、语义学习**分阶段进行**，计算开销大、跨场景泛化差，三者之间缺乏相互促进。
  - **前馈 3DGS 类方法**（如 LSM、Uni3R、C3G）：能从多视图直接重建未见场景，但语义表示**停留在类别级**，无法区分不同对象实例，也难以保持清晰的物体边界。
  - **IGGT** 虽引入了实例接地对比学习，但未构建可渲染的 3DGS 表示，无法联合进行新视图合成与语义理解。
- **核心问题**：现有方法要么具备高效泛化的重建但缺乏实例建模，要么具备实例感知理解但依赖昂贵的逐场景优化。**一个统一的、前馈的、联合学习重建-实例-语义的框架仍然缺失。**

## 二、方法论

### 2.1 核心思想
InstanceSplat 在**单次前向传播**中，从无姿态（pose-free）多视角图像构建一个"实例感知高斯表示"，将外观、几何、实例身份和语言对齐语义编码到共享的高斯原语中，并设计以实例为中心的耦合学习策略，使重建、实例学习和语义学习三者相互增强。

### 2.2 关键技术细节

**（1）Instance-Aware Gaussian Representation（实例感知高斯构建）**
- 采用 VGGT 式架构：DINOv2 主干 + 24 层 Transformer（交替的视图内/跨视图注意力）+ DPT 式几何解码器，预测相机参数、深度图、点图及高斯属性。
- 每个输入像素生成一个高斯原语，携带：位置 μ、旋转 R、尺度 s、颜色 c、不透明度 α、置信度 C、实例嵌入 S（8维）和语义特征 L。
- 借鉴 AnySplat 的**置信度感知体素化（voxelization）**策略合并冗余原语，得到紧凑的体素对齐高斯集 G′，同时融合实例和语义特征。

**（2）3D-Consistent Instance Grounding（3D 一致实例接地）**
- 采用可微渲染将高斯上的实例嵌入渲染到监督视图：S̃ᵢ = R_ins(G′, tᵢ)。
- 在渲染空间中执行**基于原型的对比学习**：
  - **Pull 项（L_pull）**：缩小像素特征与其实例原型之间的距离（intra-instance compactness）；
  - **Push 项（L_push）**：拉开不同实例原型之间的距离（inter-instance separation）；
  - **Cross-view 项（L_cross）**：对齐出现在多个视图中的同一实例原型（cross-view consistency）。
- 由于不同视图的观测通过同一组 3D 高斯耦合，得到的实例特征既**可渲染**又**跨视图一致**。

**（3）Instance-Centric Coupling（以实例为中心的耦合）**
- **边界感知重建（Boundary-Aware Reconstruction）**：从像素对齐的实例特征图计算相邻像素的余弦距离，得到软边界权重 bᵢ(p)，在实例边界处施加更强的 RGB 重建损失（Charbonnier 损失），迫使重建模型关注物体边界处的几何细节。
- **语义引导的实例判别（Semantic-Guided Instance Discrimination）**：将渲染的语义特征投影到语言对齐空间（LSeg 教师特征空间），构造实例级语义原型，用语义相似度 η 作为 push 项的权重，**对同类别相似实例施加更大的分离压力**，解决"同类难分"问题。
- **实例接地语义聚合（Instance-Grounded Semantic Aggregation）**：推理时用 HDBSCAN 聚类实例嵌入得到对象区域，在区域内**平均语义特征形成对象级原型**，再与文本嵌入匹配，将标签传播到整个实例区域，抑制逐像素语义噪声。

**（4）总训练目标**
L = L_rgb + L_distill + λ_ins·L_ins + λ_sem·L_sem + λ_bd·L_bd-rgb，其中 L_rgb 包含 MSE 和感知损失，L_distill 使用 VGGT 的伪监督约束相机位姿和深度一致性。

## 六、主要结论与发现

1. **统一前馈实例感知表示可行**：InstanceSplat 在单次前向中同时实现实例分割、开放词汇语义理解和高质量重建，无需逐场景优化。
2. **共享 3D 高斯是跨视图一致性的有效载体**：与 IGGT 相比，T-mIoU 从 61.99 提升至 64.03，T-SR 从 45.15 提升至 51.04，说明可渲染的高斯接地显著增强实例跟踪一致性。
3. **实例-语义-重建三方互促有效**：
   - 语义指导的硬负例权重提升了同类别实例的判别能力（mIoU 在多数视图设置下明显提升）；
   - 实例接地聚合显著提升语义一致性和边界质量；
   - 边界感知损失改善深度精度（RMSE 从 0.2375 降至 0.1985，AbsRel 从 0.0995 降至 0.0911）。
4. **效率优势显著**：在 LERF 上，InstanceSplat 约 **3 秒**完成重建+实例特征分配，而逐场景方法需要 55-280 分钟，同时精度更高。
5. **泛化能力强**：在未见过的 LERF 数据集上取得优于所有基线的性能。

## 七、方法优点与亮点

- **范式创新**：首次将实例身份作为高斯的内在属性（而非重建后附加），构建了真正统一的前馈实例感知 3DGS 框架；
- **双向互促设计**：通过实例中心耦合模块，让实例结构同时服务重建（边界感知）、语义（聚合单元）和实例学习（硬负例），而非单向 pipeline；
- **跨视图一致性由 3D 结构保证**：不同于在 2D 特征图上做对比学习，共享高斯使得不同视图的观测天然锚定在同一 3D 载体上，一致性和可渲染性兼具；
- **高效紧凑**：置信度感知体素化降低了冗余；总训练时间仅约 21 小时，推理约 3 秒，实用性突出；
- **语义-实例耦合的精细化设计**：语义相似度动态调制对比学习推离权重，对"同类不同实例"的难点有针对性；
- **消融实验设计完整**：每个模块均有独立消融，且与 IGGT 的对齐比较增强了可信度。

## 八、不足与局限

- **推理聚类成本**：作者自述 HDBSCAN 聚类随视图数和高斯数增加而变贵，限制了在大规模场景中的实时应用；
- **跨域鲁棒性有限**：在 LERF 上 8→16 视图时性能下降，说明域偏移下的位姿预测误差会随视图增多而累积，跨域场景的位姿鲁棒性有待加强；
- **实验场景范围集中在室内**：训练和评估均为室内数据集（ScanNet、ScanNet++、LERF），对室外大场景、动态场景的泛化能力未得到验证；
- **类别不平衡问题未充分处理**：4 视图下 mAcc 的波动反映出宏平均指标易受稀有类别影响，文中未给出消除该偏差的策略；
- **基线对比的覆盖仍有限**：未见与更多新近前馈方法（如 FLEG、TokenGS）的对比；与逐场景方法的对比仅在 LERF 少量标注视图上进行，统计显著性未讨论；
- **依赖伪标签质量**：训练依赖 VGGT 的伪深度/位姿监督和 InsScene-15K 的实例掩码质量，若输入图像质量差或掩码噪声大，效果可能受影响；
- **应用边界**：当前表示适合离线重建与理解任务，对实时增量更新的支持尚未讨论。

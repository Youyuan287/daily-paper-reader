## 摘要
零样本三维视觉定位旨在根据文本描述和三维视觉输入来定位特定物体。然而，现有方法的有效性常常受到模糊查询文本和不充分视角的显著制约。为了解决这些问题，我们提出了TDVR，一个无需训练的推理框架，该框架对输入文本进行消歧，并为零样本三维视觉定位推断准确的视角。首先，我们从三维点云中的检测实例构建语义三维场景图。随后，我们将原始查询、外观描述和空间关系描述输入大语言模型（LLM）进行融合，从而对初始输入进行消歧。我们利用思维链推理来生成消歧后查询的结构化表示。然后，以场景图和结构化查询为输入，我们通过视角推理获得最佳视角，以解决定位过程中视角缺失的问题。基于所获得的最佳视角，我们进一步区分干扰物体，使模型具备区分相似实例的能力。之后，我们通过计算特征向量的相似性，将类别文本和外观图像与查询进行匹配。最后，通过整合视角分数、混淆分数、类别分数和外观分数来识别目标物体。与以往方法相比，我们的TDVR在视角推理、相似物体区分和模糊查询理解方面具有更强的能力。在公开的ScanRefer数据集上的实验结果表明，我们的方法在Acc@0.25和Acc@0.5上分别比现有最先进方法高出15.25%和14.46%，证明了我们的TDVR在处理模糊查询文本和不足视角方面的有效性。

## Abstract
Zero-shot 3D visual grounding aims to localize specific objects based on textual descriptions and 3D visual input. However, the effectiveness of existing methods is significantly hindered by the ambiguous query text and deficient viewpoints. To address these issues, we propose TDVR, a training-free reasoning framework that disambiguates the input text and infers accurate viewpoints for zero-shot 3D visual grounding. First, we construct semantic 3D scene graph from the detected instances in the 3D point cloud. Subsequently, we put the original query, appearance and spatial relationship descriptions into the LLM for fusion, thereby disambiguating the initial input. We leverage chain-of-thought reasoning to generate the structured representation of disambiguated query. Then taking the scene graph and structured query as input, we get the optimal view via viewpoint reasoning to solve the problem of missing viewpoints during grounding. Based on the obtained optimal viewpoint, we further discriminate the distracting objects, enabling the model with the ability to distinguish similar instances. After that, we match the category text and appearance images with the query by computing the similarity of feature vectors. Finally, the target object was identified by integrating the viewpoint score, confusion score, category score, and appearance score. Compared with previous methods, our TDVR has stronger capabilities in viewpoint reasoning, similar object discrimination, and ambiguous query understanding. Experimental results on the public ScanRefer dataset show that our method outperforms the existing state-of-the-art methods by 15.25% and 14.46% in Acc@0.25 and Acc@0.5 respectively, demonstrating the effectiveness of our TDVR in addressing ambiguous query text and deficient viewpoints.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究任务**：零样本（Zero-shot）三维视觉定位（3D Visual Grounding），即给定自然语言描述和 3D 点云场景，在不使用 3D 标注训练数据的情况下，定位出目标物体。
- **核心痛点**：
  - **空间歧义**：空间关系描述（如“左边”“后面”）严重依赖说话者的观测视角；当视角未明确指定时，同一描述在不同视角下指向完全不同的物体，现有方法普遍未建模这一不确定性。
  - **文本歧义与相似物干扰**：自然语言描述往往简短且信息不充分，而室内场景中常存在大量同类、外观相似且位置相近的干扰物，模型容易陷入随机猜测。
- **研究意义**：3DVG 是具身智能和自动驾驶等领域的基础能力，解决上述问题对提升智能体在真实 3D 环境中的感知与交互能力具有重要意义。

## 2. 论文提出的方法论

### 核心思想

构建一个**无需训练（training-free）** 的 MLLM（多模态大模型）推理框架，通过“语义场景图 + LLM 查询消歧 + 视角推理 + 相似物判别 + 多模态特征匹配”的流水线，实现精确的零样本 3D 视觉定位。

### 技术流程（五个核心模块）

1. **语义 3D 场景图构建**
   - 使用 Mask3D 对点云做实例分割，每个检测实例构建节点，节点属性包含 3D 边界框、类别标签和最优 2D 裁剪图。
   - 通过相机内外参将 3D 点云投影至 2D 图像平面，并结合深度一致性检查（`|d_calc - d_map| < ε`）筛选出**最小遮挡**的 2D 视图作为外观属性。

2. **观察者中心协同消歧（Observer-Centric Synergetic Disambiguation）**
   - 利用 MLLM 从 2D 裁剪图中提取目标物体的细粒度外观描述（颜色、纹理等）。
   - 建立以相机位置为原点、水平视线方向为 Y 轴的观察者局部坐标系，选取多个锚点（anchor），生成方向性空间描述（如“某物在某物左边”）。
   - 生成同类物体之间的相对位置描述，用于区分干扰物。
   - 将原始查询与这些增强描述一并交给 LLM 融合，得到消歧后的精确查询。

3. **结构化关系抽取**
   - 通过思维链（Chain-of-Thought）推理，将消歧后的自然语言解析为四个阶段的结构化语义：目标实体及外观属性 → 锚点物体 → 标准化空间关系二元组（`<锚点, 关系>`）→ 同类内部相对方位。
   - 加入结果自检机制，格式不合格则重新抽取，保证输出结构的确定性。

4. **视角感知方向推理（Viewpoint-Aware Directional Reasoning）**
   - 理论证明：在固定旋转矩阵下，物体的相对空间关系具有旋转不变性且与旋转中心无关，因此 6 自由度视角推理可约简为**1 维水平旋转角估计**。
   - 以 10° 为步长旋转整个点云，对每个候选物体计算方向对齐得分 `Ψ`，遍历所有角度得到最优视角分数 `S_v` 和最优视角集合 `Θ_best`。

5. **基于视角的相似性解耦推理（View-based Similarity Decoupled Reasoning）**
   - 在最优视角下旋转坐标，计算同类物体集合的几何质心，以每个候选物体相对质心的位移向量与描述中同类方位参考方向的余弦相似度，得到混淆分数 `S_c`，用于区分同类相似实例。

6. **特征匹配的类别与外观评估**
   - 类别匹配：用 BERT 计算物体类别标签与目标类别文本的嵌入相似度 `S_cat`。
   - 外观匹配：用 CLIP 计算 2D 裁剪图与外观描述文本的跨模态相似度 `S_app`。

7. **目标定位**
   - 最终得分融合公式：`S_total = S_cat · (α·S_v + β·S_c + γ·S_app)`，其中经验权重 α=5、β=3、γ=1，选取得分最高的物体作为目标。

## 7. 优点

- **创新性的问题建模**：同时处理“文本歧义”和“视角缺失”两大核心挑战，且将 6-DoF 视角估计约简为 1-D 水平旋转角搜索，具有理论支撑（旋转不变性证明）。

## 8. 不足与局限

- **依赖检测器性能**：使用冻结的 Mask3D 作为实例分割前端，检测召回率直接限制了定位上限（论文在 Unique/Acc@0.25 上的“平台期”即为佐证），实际部署中需配合更强检测器。
- **LLM 成本与稳定性**：依赖 GPT-4o 和 DeepSeek-V3 两大闭源/商用 LLM，存在 API 调用成本；LLM 输出在 temperature>0 下具有随机性，虽设计了格式自检机制，但跨场景的鲁棒性尚无充分测试。
- **实验范围有限**：仅在 ScanRefer 和 Sr3D 两个室内数据集上验证，未覆盖 Nr3D（论文给出的原因是缺少相机姿态）、室外场景（如自动驾驶）或更多开源场景；对跨域泛化能力的论证不足。
- **消融报告不够细致**：表 3 仅报告 Overall 指标，未给出 Unique/Multiple 子类的消融结果，无法判断各模块在不同难度场景下的具体贡献。
- **视角推理的简化前提**：将视角推理简化为水平旋转角估计，依赖“垂直方向无歧义”的先验假设，在某些俯仰/倾斜视角更显著的真实场景中可能失效；论文未讨论该边界情况。
- **评分权重经验化**：融合权重 α=5、β=3、γ=1 为经验设定，缺乏自适应机制或敏感性分析，面对新数据集时可能需要重新调参。
- **锚点数存在“更少更好”的非单调性**：N_anc=7 时性能下降，说明该模块对上下文长度敏感，存在不稳定性。
- **Sr3D 视角标注为推断所得**：由于数据集未发布相机姿态，View-dependent 子集的评估基于重建的视角信息，可能引入一定的评估偏差。

## 摘要
近期三维视觉语言模型（3D VLMs）通过将2D视觉特征投影到世界坐标来构建几何感知令牌，从而实现如3D问答等任务的空间推理。然而，这种设计为每个场景生成数千个令牌，导致大量的计算和内存开销。尽管令牌压缩在2D VLMs中已被广泛研究，但现有方法依赖于语义相关性或基于注意力的选择，忽视了3D令牌的结构化空间特性。此外，仅靠空间邻近性无法解决3D表示中的冗余问题，因为即使经过空间聚合，物体级令牌不平衡仍然存在。为解决此问题，我们提出3DZip，一种三阶段令牌压缩框架：首先应用粗体素化去除点级冗余，然后通过行列式点过程基于特征空间多样性选择锚定令牌，最后在空间约束下合并剩余令牌以保持几何连贯性。在三个3D问答基准上的实验表明，3DZip始终优于现有压缩方法，仅用128个令牌即可保留原始性能的94.7%，并实现$1.92\times$的推理速度提升。

## Abstract
Recent 3D vision-language models (3D VLMs) construct geometry aware tokens by projecting 2D visual features into world coordinates, enabling spatial reasoning for tasks such as 3D question answering. However, this design generates thousands of tokens per scene, resulting in substantial computational and memory overhead. While token compression has been extensively studied in 2D VLMs, existing approaches rely on semantic relevance or attention-based selection that overlook the structured spatial nature of 3D tokens. Moreover, redundancy in 3D representations cannot be resolved by spatial proximity alone, as object-level token imbalance persists even after spatial aggregation. To address this, we propose 3DZip, a three-stage token compression framework that first applies coarse voxelization to remove point-level redundancy, then selects anchor tokens based on feature-space diversity via a Determinantal Point Process, and finally merges remaining tokens under spatial constraints to preserve geometric coherence. Experiments on three 3D question answering benchmarks demonstrate that 3DZip consistently outperforms existing compression methods, retaining 94.7% of the original performance with only 128 tokens, achieving a $1.92\times$ faster inference speed.

## 1. 论文的核心问题与整体含义

- **研究背景**：3D视觉语言模型（3D VLMs）通过将多视角2D视觉特征投影到世界坐标系构建几何感知令牌，从而支持空间推理任务（如3D问答）。这一范式虽然能复用强大的2D预训练表示，但每场景生成数千令牌，带来巨大的计算与内存开销。
- **核心问题**：现有2D令牌压缩方法（如基于注意力或语义相关性）忽视3D令牌的结构化空间特性；而单纯依赖空间邻近性的聚合方法又无法解决**对象级令牌不平衡**问题——即少数大物体占据不成比例的令牌预算，许多小物体得不到令牌覆盖。
- **论文意义**：首次系统地识别并分解3D多视角表示中的两种冗余（点级冗余和对象级冗余），并证明特征空间多样性是解决对象级不平衡的关键，为高效3D VLM部署提供了可行方案。

## 2. 论文提出的方法论

### 核心思想
将令牌压缩分解为三个互补阶段，分别应对不同类型的冗余：

- **点级冗余**（同一物理表面被多视角重复观测）→ 粗体素化
- **对象级冗余**（同一物体不同表面区域产生多个令牌）→ 特征多样性锚点选择
- **几何连贯性**（合并时保持空间结构）→ 空间约束令牌合并

### 方法流程（3DZip）
给定原始令牌集合 V = {vi}，压缩为 V′：

1. **Stage 1：粗体素化（Coarse Voxelization）**
   - 按体素边长 δ=0.2m 划分3D空间，对同一体素内的令牌进行**均值池化**聚合
   - 消除多视角投影产生的点级重复令牌，得到 Vvox

2. **Stage 2：特征多样性引导的锚点选择（Feature-Diversity Guided Anchor Selection）**
   - 将体素特征 L2 归一化，构建余弦相似度核 Lkl = f̂kᵀf̂l
   - 通过**行列式点过程（DPP）**的贪心最大化（基于Cholesky分解）选取 K 个特征多样性最强的锚点令牌 A
   - 与空间坐标距离（XYZ-DPP）相比，特征距离能更均匀地覆盖物体实例，对象覆盖率从51%提升至70%

3. **Stage 3：空间约束令牌合并（Spatially-Constrained Token Merging）**
   - 对每个非锚点令牌，在特征空间中找到最近锚点 a* (j)
   - 当体素网格空间距离 dg(j, a*) ≤ τg（τg=5）时合并，否则丢弃
   - 锚点特征更新为自身与分配令牌的均值，位置保持不变

## 6. 论文的主要结论与发现

1. 投影式3D VLM中存在两类不同冗余：点级冗余（多视图重复观测）和对象级冗余（同一物体多表面对应不同表面令牌）
2. **仅空间聚合无法解决对象级令牌不平衡**；特征级多样性是平衡对象覆盖的关键
3. 3DZip 在**128 个令牌（保留9.1%）+ 下保留原模型性能的94.7%**（相对准确率），相比原始1410个令牌实现 **1.92 倍**更快推理
4. 相比2D压缩方法（FastV、VisionZip等）和3D感知方法（DTC），3DZip 在**所有令牌预算**下均取得最佳结果，尤其是在64/32的低预算下保持显著性能优势（如SQA3D@32：51.1 vs. 最高基线48.8）
5. 特征空间距离在锚点选择中优于空间距离，说明语义多样性而非几何分散是更优的选择标准
6. 粗体素化是必要的预处理步骤，但过大体素会破坏细粒度空间线索（δ=0.3m时性能下降）

- **方法简洁有效**：三阶段各司其职、互补性强，既有理论依据（DPP）又有工程实用性（训练无关、即插即用）

## 8. 不足与局限

- **小物体细粒度信息损失**：粗体素化会合并小物体与邻近物体/背景，在fine detail和小物体类别上低于仅使用Stage 2+3的w/o Voxel变体（29.8 vs. 30.5 和 19.5 vs. 21.6 EM）
- **超参数固定**：体素大小 δ 和空间阈值 τg 固定，不随场景复杂度/物体密度自适应；虽然灵敏度分析表明固定设置在总体上仍有最好的折衷，但密集小场景更偏好较小的 δ 和 τg
- **场景大小适应性不足**：小场景（1.30 objects/m³）与大场景（0.37 objects/m³）的最优超参数不同，固定设置在不同环境中可能次优
- **评估集中于ScanNet室内场景**，未验证HM3D和室外场景（OpenEQA的HM3D部分因官方轨迹状态不可用而未评估，评估覆盖存在一定缺口）
- **骨干模型覆盖有限**：虽验证了三个投影式3D VLM，但未涵盖所有主流3D VLM架构

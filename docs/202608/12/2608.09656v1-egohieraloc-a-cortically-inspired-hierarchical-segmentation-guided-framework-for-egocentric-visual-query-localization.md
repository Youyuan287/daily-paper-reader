## 摘要
视觉查询定位（VQL）旨在自我中心视频中检索并重新定位查询对象，但当对象边界模糊且全局上下文无法有效引导细粒度定位时，这一任务仍具挑战性。人类视觉通过层次化过程处理此类模糊性：快速筛选前景候选，在干扰物中选择性注意目标，通过全局上下文与局部细节之间的反馈细化感知，并且在单视角不可靠时，根据其可信度跨视角整合证据。受这些能力的启发，我们提出了 \textbf{EgoHieraLoc}，一个用于VQL-2D和VQL-3D的统一框架。判别性解析模块首先利用分割先验提取前景感知的查询表示；查询感知模块随后通过具有可变形建模的判别性相关滤波执行鲁棒的目标定位；区域适应模块将多尺度上下文反馈至局部区域以恢复精确的目标边界。为将此感知层次扩展至3D定位，我们引入了几何-语义联合置信度（GSJC），该置信度将分割置信度与局部深度一致性、多视图反投影一致性和三角测量基线质量相乘耦合，使得视图仅在语义和几何上均可信时才有助于3D估计。大量实验证明该方法在VQL-2D和VQL-3D基准上均达到最先进性能。

## Abstract
Visual query localization (VQL) aims to retrieve and re-localize a queried object in egocentric videos, yet remains challenging when object boundaries are ambiguous and global context cannot effectively guide fine-grained localization. Human vision handles such ambiguity through a hierarchical process: it rapidly screens foreground candidates, selectively attends to the target despite distractors, refines perception via feedback between global context and local detail, and, when a single view is unreliable, integrates evidence across viewpoints according to its credibility. Inspired by these competencies, we propose \textbf{EgoHieraLoc}, a unified framework for VQL-2D and VQL-3D. A Discriminative Parsing Module first extracts foreground-aware query representations using segmentation priors; a Query-Aware Module then performs robust target localization through discriminative correlation filtering with deformable modeling; and a Regional Adaptation Module feeds multi-scale context back into local regions to recover precise object boundaries. To extend this perceptual hierarchy to 3D localization, we introduce Geometric-Semantic Joint Confidence (GSJC), which multiplicatively couples segmentation confidence with local depth consistency, multi-view back-projection consistency, and triangulation-baseline quality, so that a viewpoint contributes to the 3D estimate only when it is credible both semantically and geometrically. Extensive experiments demonstrate state-of-the-art performance on both VQL-2D and -3D benchmarks.

### 1. 核心问题与整体含义

- **任务定义**：视觉查询定位（VQL）要求在自我中心视频中根据给定的查询图像，检索并重新定位目标对象的最终出现位置，输出为2D边界框（VQL-2D）或3D世界坐标位移（VQL-3D）。
- **核心挑战**：现有方法通常假设查询目标具有清晰可见的边界，但在真实的第一人称视频中，运动模糊、遮挡、剧烈尺度变化和背景干扰使边界模糊，全局上下文难以有效引导细粒度定位；同时，2D与3D任务在传统流程中相互割裂（语义匹配 vs. 几何重建），缺乏共享表示来让语义证据调制几何融合。
- **人类视觉启发**：人类视觉系统通过“粗略筛选 → 选择性注意 → 反馈细化 → 按可信度跨视角整合”的层级机制应对模糊性。作者将这一过程映射到EgoHieraLoc中，旨在统一解决2D和3D定位任务。

### 2. 方法论

#### 核心思想
EgoHieraLoc 将人类视觉的四种能力实例化为三个协作的2D模块和一个3D几何融合方案，形成从语义引导到几何细化的感知流程。

#### 2D分支（三个模块）

- **判别性解析模块（DPM）** ——模拟“快速前景筛选”
  - 使用SAM（Segment Anything Model）对查询图像生成二元分割掩码。
  - 将掩码与骨干网络提取的查询特征空间对齐，划分前景特征集 \(M_O\) 和背景特征集 \(M_B\)。
  - 对搜索区域特征经两个CBN层处理后，按空间位置分别计算与前景/背景特征集的余弦相似度，并采用Top-K平均聚合得到前景评分 \(O\) 和背景评分 \(B\)，最终通过softmax生成似然通道图 \(Z\)。
  - 功能：利用分割先验将目标与背景分离，提升查询表示的判别力。

- **查询感知模块（QAM）** ——模拟“选择性注意”
  - 基于判别相关滤波（DCF），在频域中对查询特征求解闭式岭回归问题，获得滤波器 \(f^*\)。
  - 将滤波器应用于每个视频帧，得到响应图 \(R_{v_i}\)；采用自适应阈值二值化提取多个连通区域中的峰值候选（Top-5），并通过响应强度与区域面积加权选择主候选。
  - 引入两级时域平滑机制：瞬时形变 \(\Delta(v_i)\) 与累积形变 \(\Omega(v_i)\)（指数衰减），以抑制抖动。
  - 使用动态椭圆参数化目标形状，通过递归更新半轴长度，并施加各向异性空间先验，结合运动补偿距离度量修正最终位置。
  - 功能：在面对干扰物和尺度变化时保持目标身份的连续性与空间一致性。

- **区域适应模块（RAM）** ——模拟“反馈式细化”
  - 采用金字塔Transformer骨干（PVT），通过四个阶段生成多尺度特征，其中用维度折叠模块（DCM）替代标准多头注意力降低计算复杂度。
  - 将DPM和QAM输出的定位热图与多尺度特征融合，通过卷积和上采样逐步恢复高分辨率分割结果。
  - 功能：将全局上下文与局部细节关联，隐式实现自上而下的反馈调节，恢复目标精确边界。

#### 3D分支：几何-语义联合置信度（GSJC）

- **2D到3D反投影**：从预测分割掩码生成边界框中心，结合深度估计（Depth Anything）与相机位姿（COLMAP/SfM），用置信度加权深度聚合进行反投影，得到每个候选帧的3D点。
- **GSJC权重构成**（四个因子乘法耦合）：
  - **语义置信度** \(\vartheta_{sem}\)：由掩码内平均置信度 \(P_{ave}\)、高置信度像素集中度 \(P_{thr}\)、峰值置信度 \(P_{max}\) 组合得到。
  - **深度一致性** \(\varpi_{depth}\)：基于掩码内深度方差，方差越低权重越高。
  - **重投影一致性** \(\varpi_{reproj}\)：将候选帧的三角化均值点重投影回各帧，计算与原2D观测的偏差，偏差越小权重越高。
  - **三角测量基线质量** \(\varpi_{tri}\)：以射线方向与均值方向的夹角正弦值衡量，正交基线更稳定。
  - 四个因子相乘得到每帧的最终权重 \(\tilde{\vartheta}_i\)，并设置下界防止数值下溢；最终3D位置为所有候选帧加权平均（在极端不可靠时退化为均匀平均）。
- **单向信息流**：2D语义置信度调制3D几何可靠性，但3D估计不回传修改2D预测，避免循环依赖，保持各阶段输入输出契约透明。

- **可迁移性强**：在不额外依赖外部检测器的情况下，在多个跟踪基准上达到SOTA，证明了方法的通用潜力。

### 8. 不足与局限

- **基准单一**：VQL任务的公开基准目前仅Ego4D-VQ，缺乏在其他VQL数据集上的独立验证，以检验跨数据集泛化能力。
- **3D鲁棒性依赖前置模块**：VQL-3D性能受制于COLMAP相机位姿估计和Depth Anything深度质量；对动态场景、快速自运动或纹理贫乏环境，这些前置模块可能失效，而文中对这类耦合误差缺乏深入研究。
- **计算开销未完全透明**：推理效率分析仅针对2D分支，3D流程中的SfM和深度估计耗时未纳入，实际端到端部署的成本可能远高于报告值；训练阶段GPU数量、时长等关键信息缺失。
- **SAM失败的极端情况**：虽设计了三级降级回退机制，但在特征级模糊、透明物体、极小目标、严重遮挡等极端场景下，性能仍有明显上限（见附录F失败分析），说明纯外观匹配的固有局限。
- **超参数微调成本**：QAM中多个超参数（阈值、衰减、平滑、椭圆权重）需针对新数据集进行网格重调，虽敏感性分析表明影响幅度有限，但仍可能降低方法的即插即用性。
- **QwP指标不敏感**：在消融中QwP恒定不变，意味着该指标无法反映模型贡献，实验展示中需依赖Succ、L2等指标，可能误导对模型效用的全面评估。
- **对比公平性**：部分基线方法（如RELOCATE）是训练无关方法，与端到端训练方法直接比较时，算力和训练数据差异可能造成不公平因素，论文未详细讨论这一点。

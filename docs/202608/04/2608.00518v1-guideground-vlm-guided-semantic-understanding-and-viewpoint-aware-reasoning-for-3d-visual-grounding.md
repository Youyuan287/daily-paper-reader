## 摘要
3D视觉定位旨在根据自然语言查询在3D场景中定位目标对象，这需要细粒度的语义理解和依赖于视点的空间推理。现有方法通常将语义理解表述为辅助的闭集对象分类任务，并依赖多视图特征聚合进行视点推理，这限制了语义泛化并削弱了视点特定的证据。我们观察到，视觉语言模型通过开放词汇语义理解和全局场景感知自然地提供了互补能力。基于这一洞察，我们提出了GuideGround，一个VLM引导的框架，通过利用VLM进行语义增强和视点特定假设验证，补充而非替代任务特定的定位模型。具体来说，我们用VLM生成的对象语义描述替代辅助的闭集对象分类，以增强语义理解。同时，我们不直接聚合多视图表示，而是通过逐视图定位保留视点特定的定位假设，并使用VLM在候选视点间显式验证这些假设。在ReferIt3D基准上的大量实验表明，GuideGround持续优于之前的最先进方法。全面的消融研究进一步证实了所提出的语义理解和视点推理策略的有效性。

## Abstract
3D visual grounding aims to localize the target object in a 3D scene from a natural language query, requiring both fine-grained semantic understanding and viewpoint-dependent spatial reasoning. Existing methods typically formulate semantic understanding as an auxiliary closed-set object classification task and rely on multi-view feature aggregation for viewpoint reasoning, limiting semantic generalization and weakening viewpoint-specific evidence. We observe that vision-language models naturally provide complementary capabilities through open-vocabulary semantic understanding and global scene perception. Based on this insight, we propose GuideGround, a VLM-guided framework that complements rather than replaces task-specific grounding models by leveraging VLMs for semantic enhancement and viewpoint-specific hypothesis verification. Specifically, we replace auxiliary closed-set object classification with VLM-generated object semantic descriptions to enhance semantic understanding. Meanwhile, instead of directly aggregating multi-view representations, we preserve viewpoint-specific grounding hypotheses through per-view grounding and explicitly verify them using VLMs across candidate viewpoints. Extensive experiments on the ReferIt3D benchmark demonstrate that GuideGround consistently outperforms previous state-of-the-art methods. Comprehensive ablation studies further confirm the effectiveness of both the proposed semantic understanding and viewpoint reasoning strategies.

## 2. 论文提出的方法论（GuideGround）

### 2.1 总体框架（两阶段）

论文提出**GuideGround**框架，包含两个阶段：

1. **语义理解阶段**：利用预训练VLM生成对象语义描述，并将查询解析为目标描述与锚点描述，建立语义先验。
2. **视点感知空间推理阶段**：先在每个候选视点上独立执行锚点感知定位，产生视点特定定位假设；再由VLM基于场景级视觉观察验证假设，确定最终定位结果。

### 2.2 VLM引导的语义理解模块

- **对象语义表示**：将分割对象的3D点投影回RGB图像，通过关键帧选择策略选出多个信息量最大的视角，拼成2×2拼图（collage），输入预训练VLM M_cap生成对象描述 (t_o, c_o)——其中t_o为简洁对象描述，c_o为包含更丰富外观细节和上下文信息的全面语义描述。
- **查询语义解析**：用LLM M_par从查询Q中提取目标描述t_Q和锚点描述集合A={a_1, ..., a_K}。目标描述用于估计语义对应，锚点描述用于引导锚点感知空间推理。
- **语义先验构造**：使用同一句子嵌入模型M_sent编码c_o和t_Q，计算余弦相似度作为语义先验分数：

  **s_sem_o = (e_o^T · e_t) / (‖e_o‖ · ‖e_t‖)**

### 2.3 视点感知空间推理

将视点空间推理分解为**逐视点定位**和**假设验证**两阶段：

#### (1) 逐视点定位（Per-view Grounding）

包含三个顺序模块（在单个视点v下表述）：

- **查询感知融合模块（QFM）**：融合对象语义特征、粗略几何线索和语言查询，生成查询条件化对象表示f_i^v。基于MiKASA的语言-空间融合设计，但将PointNet++点云特征替换为语义理解模块生成的对象描述语言嵌入。
- **锚点感知细化模块（ARM）**：
  - 锚点定位：通过计算锚点短语嵌入与对象表示的相似度（带温度参数τ）得到锚点-对象对应概率p_i^v；
  - 锚点感知消息构建：联合编码相对几何关系r_ij、对象特征和锚点短语表示，通过MLP生成消息m_i^v；
  - 门控残差注入：聚合所有有效锚点消息后，通过可学习残差门γ注入查询条件化表示。
- **定位假设生成（GHG）**：融合语义一致性分数s_sem、粗粒度定位分数s_coarse和关系感知分数s_rel：

  **s_i^v = λ_s · s_sem_i + λ_c · s_coarse_i^v + λ_r · s_rel_i^v**

  预测对象为最高分对应的对象，形成该视点下的定位假设。

#### (2) VLM假设验证

- **触发条件**：当所有视点预测一致时直接接受；当最高分与次高分差大于置信度阈值δ时也直接接受；否则进入VLM验证阶段。
- **假设构造**：每个视点生成包含互补视觉和语义证据的验证假设H_v = {I_top^v, ŷ_v, P_v}——包括俯视场景可视化（高亮预测目标及相关对象）、视点定位预测和上下文对象的语义描述。
- **VLM验证**：将各视点假设和语言查询一同输入验证VLM M_ver，由其判定与查询最一致的定位结果。与端到端VLM方法不同，VLM只负责比较和选择候选假设，空间推理仍由专用定位模型完成。

### 2.4 训练目标

- 仅优化逐视点定位模块，语义理解和假设验证模块保持冻结。
- **跨视点分数聚合**：训练时将各视点定位分数取平均获得聚合分数（避免视点间不一致的优化信号），推理时保留逐视点假设用于VLM验证。
- **总损失**：L = L_ref + λ_a·L_anchor + λ_d·L_dis，其中L_ref为交叉熵定位损失，L_anchor为锚点对应损失（多正样本），L_dis为硬负样本排序损失（拉开目标与同类干扰物的分数差距）。

## 6. 主要结论与发现

- **VLM补充优于替代**：预训练基础模型作为专用3D定位框架内的互补语义和推理组件时，效果远优于直接作为独立预测器使用（68.1% vs. 53.2% SeqVLM零样本SOTA）。
- **语义理解**：用VLM生成的开放词汇语义描述替代辅助闭集分类，一致提升所有子集上的定位性能（从64.4%提升至68.1%）；单纯组合PN++和CLIP特征而不引入显式语义先验无法超越PointNet++基线。
- **视点推理**：保留视点特定定位假设并用VLM验证（66.6% VD精度）优于传统多视图特征融合（63.2% VD）；VLM直接推理（文本或文本+图像）效果显著较差，验证了结构化空间推理的必要性。
- **组件互补**：ARM（锚点感知）和VLM假设验证分别贡献关键提升（移除后分别降至63.4%和65.2%），两者产生互补性收益。
- **视点数量**：4个候选视点是最优权衡（8个视点引入冗余假设反而降低性能）。
- **错误分析**：验证模块修正的样本中约69%（189/275）归因于空间推理修复，表明VLM验证的核心价值在于解决空间歧义；语义增强主要提升Easy子集，空间验证主要改善Hard和VD子集。

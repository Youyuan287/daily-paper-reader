## 摘要
开放词汇3D场景图为语言引导导航提供了紧凑的语义记忆，但映射对象通常通过单一融合特征或确定的语义标签暴露。这种确定性可能将少数但任务相关的假设从任务时接口中移除。我们提出OpenBelief-Nav，一种证据保持的对象记忆，它保留观察级短语、可靠性线索和帧掩码来源，同时维护独立的聚合几何和视觉表示。语义相关的短语被整合为与词汇无关的对象信念，任务特定的读取从中执行固定词汇投影或自由形式检索。在五个ScanNet200和八个Replica场景中，全信念投影的mIoU分数分别为0.2742和0.2912，而匹配的早期承诺读取为0.2393和0.2701。在78次HM3D-YCB导航试验中，共识和早期承诺检索均达到60/78次成功，而信念加权检索为58/78次，DualMap为55/78次。在20次Unitree G1运行中，组织为10个匹配的评估案例，允许最多两次验证候选尝试的纠正策略将目标确认成功率从6/10提高到8/10，相对于仅顶层执行。代码将在接受后于https://openbelief-nav.github.io/发布。

## Abstract
Open-vocabulary 3D scene graphs provide compact semantic memory for language-guided navigation, but mapped objects are often exposed through a single fused feature or committed semantic label. Such commitment can remove minority yet task-relevant hypotheses from the task-time interface. We present OpenBelief-Nav, an evidence-preserving object memory that retains observation-level phrases, reliability cues, and frame-mask provenance while maintaining separate aggregate geometric and visual representations. Semantically related phrases are consolidated into a vocabulary-independent object belief from which task-specific readouts perform fixed-vocabulary projection or free-form retrieval. On five ScanNet200 and eight Replica scenes, full-belief projection achieves mIoU scores of 0.2742 and 0.2912, compared with 0.2393 and 0.2701 for a matched early-commit readout. Across 78 HM3D-YCB navigation trials, consensus and early-commit retrieval each achieve 60/78 successes, compared with 58/78 for belief-weighted retrieval and 55/78 for DualMap. Across 20 Unitree G1 runs organized as 10 matched evaluation cases, a correction policy permitting at most two verified candidate attempts improves target-confirmation success from 6/10 to 8/10 relative to top-1-only execution. Code will be released upon acceptance at https://openbelief-nav.github.io/.

- 开放词汇 3D 场景图为语言引导导航提供了紧凑的语义记忆，但现有方法通常将每个映射对象压缩为**单一融合特征**或**确定性语义标签**。
- 这种“早期语义承诺”（early semantic commitment）会导致少数但任务相关的语义假设被丢弃，无法在任务时恢复。
- 例如，同一物体在不同视角下可能被描述为不同短语，而多数投票或平均嵌入可能掩盖少数的正确假设。
- 论文提出**OpenBelief-Nav**，通过**延迟语义承诺**，在对象记忆中保留所有观测级语言证据、可靠性线索和帧掩码来源，使得语义决策可以在任务时根据具体需求重算，从而提升开放词汇导航与分割的鲁棒性和灵活性。

## 2. 方法论

### 核心思想
- 对象节点存储**证据**而非**决策**：保留观察级短语、可靠性线索、帧掩码来源，同时维护独立的聚合几何（点云）与聚合视觉特征。
- 语义相关短语被整合为**词汇无关的对象信念**（belief），任务时通过不同读出头消费同一份证据。

### 关键技术细节

- **多模态证据采集**：VLM 提出物体短语，SAM 生成掩码，保留短语、帧、掩码索引、分割置信度、有效点数、点云和视觉特征。
- **几何-视觉关联**：基于点云重叠和视觉相似度进行保守关联，避免早绑定语义，防止错误合并。

## 6. 主要结论与发现

- **延迟语义承诺是有益的**：在固定词汇分割中，全信念投影的 mIoU 最高（ScanNet200 0.2742，Replica 0.2912），显著优于早期承诺（0.2393 / 0.2701）。
- **不同任务需要不同读出头**：分割任务偏好全信念，导航任务中共识和早期承诺检索最优（成功率 76.9%），信念加权检索稍低（74.4%），但仍高于 DualMap（70.5%）。
- **执行纠正有效**：在真实机器人测试中，纠错机制将目标确认成功率从 6/10 提升到 8/10，尤其在有混淆对象条件下从 20% 提升到 60%。
- **消融显示**：统一权重和移除低证据正则化会明显降低性能；无同义词整合造成轻微下降；保留更多假设有助于下游投影任务。

## 7. 优点

- 提出“证据保持”的对象记忆范式，明确区分“存储证据”与“任务时决策”，概念清晰且实用。
- 支持多种任务时读出头，且保证对比时共享同一冻结图，实验设计较为严谨。
- 将语义分隔成“投影”和“自由检索”两类接口，并与执行期验证结合，形成闭环。
- 真实世界验证采用配对案例设计（相同图、查询、配置、起始位姿），控制变量较好。
- 使用较新的预训练模型（Qwen3-VL、SAM 3、MobileCLIP2），部分体现了当前前沿水平。
